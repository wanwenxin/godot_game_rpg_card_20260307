## 🎮 游戏简介

本作是一款**单机卡牌构筑游戏**。玩家扮演移动基地的指挥官，在资源匮乏的荒野中进行**远征（Run）**。通过**卡牌战斗**获取资源，在**局外建设基地**，利用**消耗品构筑**与**环境交互**，最终实现数值破格的爽快战斗。

### 核心特色

- **基地经营**：升级建筑，解锁新卡和消耗品
- **类搜打撤**：远征获取资源，失败会损失部分物资
- **环境博弈**：9 种环境类型，利用环境克制敌人
- **12 卡牌流派**：从雷霆传导到时序断裂，多种构筑可能
- **机制杀**：用特定方式击杀 BOSS，触发隐藏奖励

## 🚀 快速开始

### 环境要求

- **引擎**：Godot 4.6+
- **平台**：Windows 10/11, macOS 10.14+, Linux

### 运行游戏

```bash
# 克隆项目
git clone https://github.com/wanwenxin/godot_game_rpg_card_20260307.git

# 进入项目目录
cd godot_game_rpg_card_20260307

# 使用 Godot 打开项目
godot project.godot
```
