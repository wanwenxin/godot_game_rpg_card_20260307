## 🎮 游戏简介

**原点移动**是一款以中世纪到工业革命早期混合时代为背景的卡牌构筑 Roguelike 游戏。玩家扮演移动堡垒的指挥官，探索被虚空污染的荒野，收集资源，强化自身，揭开大灾变的真相。

### 核心特色

- **时代背景**：中世纪到工业革命早期的混合时代，中西方文化结合，低魔设定
- **7 名角色**：人类为主（6 名人类，1 名精灵），女性为主（5 名女性，2 名男性），中西方结合（东方 3 名，西方 4 名）
- **21 个流派分支**：每名角色拥有 3 个专属流派分支，共 21 个流派，体现差异化特色
- **7 级卡牌品级**：从粗糙到神话，卡牌可升级强化
- **词条系统**：独立于品级的词条系统，自由组合到卡牌上
- **6 张远征地图**：从边境荒野到天空城，难度递增
- **环境系统**：9 种环境类型，影响战斗策略
- **基地建设**：7 大建筑，局外成长系统

## 🛠️ Godot 4.6 技术要点

### 核心架构

- **Resource 驱动模式**：使用 `.tres` 文件存储卡牌、环境、状态数据
- **场景树结构**：BattleStage、EnvironmentManager、CardManager、UI_Layer
- **信号总线**：GameEvents.gd 单例进行跨模块通信

### 关键实现

- **环境系统**：WorldEnvironment 节点 + Shader 全局参数
- **卡牌系统**：Area2D 检测拖拽 + Tween 动画
- **伤害计算**：DamageCalculator 静态类
- **对象池**：预实例化数字飘字和粒子特效

详细实现见：**开发细节.txt**

## 📊 数值框架摘要

### 伤害公式

```
基础伤害 = 卡牌基础值 + 状态加成
环境修正 = 基础伤害 × 环境倍率
暴击修正 = 环境修正 × (1 + 暴击率 × 暴击倍率)
最终伤害 = 暴击修正 - 目标防御力 (最低为 1)
```

### 基础参数

| 参数 | 默认值 |
|:---|:---|
| 基础能量 | 3 点/回合 |
| 初始手牌 | 5 张 |
| 每回合抽牌 | 3 张 |
| 暴击率 | 5% |
| 暴击倍率 | 1.5 |

详细数值见：**数值设计文档.txt**
