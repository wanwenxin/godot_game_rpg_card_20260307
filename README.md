## 一、游戏简介

### 1.1 游戏概述

**弃刃从牌**是一款以中世纪到工业革命早期混合时代为背景的卡牌构筑 Roguelike 游戏。玩家扮演移动堡垒的指挥官，探索被虚空污染的荒野，收集资源，强化自身，揭开大灾变的真相。

### 1.2 核心特色

| 特色 | 说明 |
|:---|:---|
| **时代背景** | 中世纪到工业革命早期的混合时代，中西方文化结合，低魔设定 |
| **7 名角色** | 人类为主（6 名人类，1 名精灵），女性为主（5 名女性，2 名男性），中西方结合（东方 3 名，西方 4 名） |
| **21 个流派分支** | 每名角色拥有 3 个专属流派分支，共 21 个流派，体现差异化特色 |
| **7 级卡牌品级** | 从粗糙到神话，卡牌可升级强化 |
| **词条系统** | 独立于品级的词条系统，自由组合到卡牌上 |
| **6 张远征地图** | 从边境荒野到天空城，难度递增 |
| **环境系统** | 11 种环境类型，影响战斗策略 |
| **基地建设** | 5 大建筑，局外成长系统 |

## 二、世界观与背景

### 2.1 时代背景

世界处于魔法与机械交汇的转折点：
- 东方仍保留着传统王朝与宗门体系
- 西方已出现蒸汽机械与早期工业
- 魔法稀有且危险，属于"低魔"设定
- 冷兵器与早期火器并存

### 2.2 历史脉络

#### 大灾变前——双元纪元

**东方（天朝上国）**：
- 墨家机关术鼎盛，创造自动傀儡与机械城
- 道门占星术预测天象，指导国运
- 武林门派传承武艺与内功心法
- 炼金术士炼制丹药与法器

**西方（诸王国）**：
- 圣教骑士团守护信仰与正义
- 精灵族与自然和谐共存
- 蒸汽工匠公会兴起，机械技术萌芽
- 炼金公会研究元素与物质转化

#### 大灾变——虚空降临

**灾变原因**：东西方法师联合试图打开"原点之门"获取无限能量，虚空能量泄露，污染了世界，魔法平衡被打破，元素暴走。

**灾变影响**：
- 大陆破碎，形成荒野与隔离带
- 魔物横行，文明退居少数移动堡垒
- 魔法变得稀有且危险
- 古代遗迹散落各地，蕴含失落知识

#### 当前世界——新纪元 500 年

- 人类在移动堡垒中生存
- 冒险者探索荒野，收集古代遗物
- 虚空威胁仍在，但已减弱
- 新的势力正在崛起

### 5.3 综合计算公式

#### 资源获取公式
```
星尘获取 = (普通敌人数量 × 25 + 精英数量 × 60 + BOSS 数量 × 150) 
           × K_difficulty × K_map × K_refine

星核获取 = (精英数量 × 8 + BOSS 数量 × 25) 
           × K_difficulty × K_map × K_refine
```

#### 伤害计算公式
```
基础伤害 = 卡牌基础值 + 状态加成
环境修正 = 基础伤害 × K_env
暴击修正 = 环境修正 × (1 + 暴击率 × (K_crit - 1))
防御修正 = 暴击修正 × K_def
最终伤害 = max(1, 防御修正)
```

#### 敌人强度公式
```
敌人实际 HP = 敌人基础 HP × K_difficulty × K_map
敌人实际攻击 = 敌人基础攻击 × K_difficulty × K_map
```

## 十、难度系统

### 10.1 远征难度等级（5 级）

**每个地图的难度解锁独立**

| 难度 | 系数值 | 解锁条件 | 敌人强度 | 资源获取 | 生命恢复 | 特殊效果 |
|:---:|:---:|:---|:---:|:---:|:---:|:---|
| **和平** | 0.5 | 默认解锁 | 50% | 1.5x | 100% | 初始能量 +1，敌人攻击频率 -20% |
| **日常** | 1.0 | 默认解锁 | 100% | 1.0x | 30% | — |

| **噩梦** | 2.0 | 通关该地图 1 次 | 200% | 0.8x | 0% | 敌人攻击频率 +20%，暴击率 +10% |
| **末日** | 3.0 | 通关该地图 1 次 | 300% | 0.7x | 0% | 初始能量 -1，敌人攻击频率 +30%，暴击率 +20% |

### 10.2 地图难度解锁规则

```
每个地图独立追踪难度解锁状态：

1. 首次解锁新地图时，默认解锁【和平】和【日常】两个难度
2. 通关该地图任意难度 1 次后，解锁【危险】、【噩梦】、【末日】三个难度
3. 每个地图的进度独立，互不影响
```

## 十一、远征准备系统

### 11.1 角色选择

**角色选择界面布局**：
- 已解锁角色显示立绘和头像
- 未解锁角色显示剪影和解锁条件
- 点击角色可查看详细信息（背景、流派、台词）
- 确认选择后进入流派与卡组构建

### 11.2 流派与卡组构建

**初始流派选择**：
- 每名角色拥有 3 个专属流派
- 玩家选择其中一个作为本次远征的流派
- 选择后确定初始卡组构成

**卡组编辑规则**：
| 规则 | 说明 |
|:---|:---|
| 最少卡牌数 | 由战争学院等级决定（20-10 张） |
| 最大卡牌数 | 由募兵所等级决定（30-40 张） |
| 初始卡组 | 包含本流派下所有的 1 级卡 |
| 可调整 | 可从背包添加/移除卡牌 |

### 11.3 卡牌合成系统

**合成界面布局**：
- 左侧：可合成的卡牌列表（按流派筛选）
- 右侧：合成预览（品级、词条）
- 底部：资源显示和合成按钮

**合成消耗计算**：
```
实际合成消耗 = 基础消耗 × K_craft
K_craft = 1.0 - (锻造工坊等级 × 0.03)
K_craft_min = 0.70（最低 70%）
```

**品级选择**：
- 1-3 级卡牌消耗星尘
- 4-7 级卡牌消耗星核
- 品级越高，基础数值和效果越强

**词条附加**：
- 合成时可选择是否附加词条
- 词条随机生成，可消耗额外资源重随
- 词条独立于品级，自由组合

**合成确认与撤销**：
- 合成确认后，卡牌进入背包
- 在远征开始前可撤销合成，返还 50% 消耗

### 11.4 远征配置

**地图选择**：
- 6 张远征地图，按解锁顺序排列
- 显示每张地图的难度系数、主要环境、敌人品级

**难度选择**：
- 5 个难度等级，根据解锁状态可选
- 显示难度效果（敌人强度、资源获取、生命恢复）

**最终确认**：
- 确认地图和难度选择
- 保存远征配置
- 进入远征

### 12.1 游戏状态机

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│   BOOT   │────▶│  TITLE   │────▶│   BASE   │
└──────────┘     └──────────┘     └─────┬────┘
                                         │
                                         ▼
                                   ┌──────────┐
                                   │MAP_SELECT│
                                   └─────┬────┘
                                         │
                                         ▼
                                   ┌──────────┐
                                   │EXPEDITION│◀───────┐
                                   └─────┬────┘        │
                                         │             │
                                   ┌─────┴─────┐       │
                                   │           │       │
                                   ▼           ▼       │
                              ┌─────────┐ ┌─────────┐  │
                              │ BATTLE  │ │ RESULT  │──┘
                              └────┬────┘ └────┬────┘
                                   │           │

                                         │

                                   │GAME_OVER │
                                   └──────────┘
```

### 12.2 状态切换触发条件

| 当前状态 | 目标状态 | 触发条件 | 数据传递 |
|:---|:---|:---|:---|
| BOOT | TITLE | 初始化完成 | 无 |
| TITLE | BASE | 点击继续游戏/新游戏 | 加载存档或创建新存档 |
| BASE | MAP_SELECT | 点击指挥中心 | 传递玩家当前资源 |
| MAP_SELECT | EXPEDITION | 确认地图和难度 | 传递 map_id, difficulty |
| EXPEDITION | BATTLE | 进入战斗节点 | 传递 enemy_config, environment |
| BATTLE | RESULT | 战斗结束（胜/负） | 传递 battle_result, rewards |
| RESULT | EXPEDITION | 继续远征 | 更新远征进度 |
| RESULT | BASE | 返回基地 | 保存远征进度，发放奖励 |
| EXPEDITION | GAME_OVER | 玩家 HP≤0 或通关 | 传递 final_result |

### 12.3 基地场景互动

**基地主界面**：
- 基地剖面背景
- 5 大建筑显示（锻造工坊、药剂师协会、战争学院、募兵所、精炼工厂）
- 资源栏显示（星尘、星核、卡组数量、HP）
- 功能按钮（开始远征、调整卡组、查看收藏、成就、设置、退出）

**建筑升级流程**：
1. 点击建筑，打开升级界面
2. 显示当前等级、效果、升级消耗
3. 确认升级，扣除资源
4. 更新系数，保存数据
5. 返回基地主界面

### 12.4 远征地图场景

**地图加载与节点生成**：
1. 加载地图配置
2. 生成节点（10-15 个）
3. 连接路径
4. 绑定环境
5. 设置起点

**节点类型分布**：
| 节点类型 | 占比 | 说明 |
|:---|:---:|:---|
| 起点 | 固定 | 第 1 个节点，安全 |
| 战斗 | 50-60% | 普通敌人战斗 |
| 营地 | 10-15% | 安全屋，恢复 |
| 奖励 | 10-15% | 三选一奖励 |
| 事件 | 10-15% | 随机事件 |
| 精英 | 5-10% | 精英敌人 |
| BOSS | 固定 | 最后节点 |

**移动规则**：
- 每个节点通常连接 1-3 个后续节点
- 玩家只能移动到相邻节点
- 不能回头移动

### 12.5 战斗场景流程

**战斗初始化**：
1. 生成敌人
2. 设置环境
3. 初始化战斗数据
4. 构建卡组
5. 抽初始手牌（5 张）
6. 播放入场动画
7. 开始玩家回合

**回合制循环**：
```
玩家回合开始
    │
    ▼
1. 回合数 +1
2. 重置能量到最大值
3. 抽 3 张牌
4. 更新敌人意图显示
    │
    ▼
玩家行动阶段
- 使用卡牌（消耗能量）
- 卡牌效果即时结算
- 检查胜利条件
    │
    ▼
玩家点击「结束回合」
    │
    ▼
敌人回合开始
    │
    ▼
敌人行动阶段
- 攻击：计算伤害，玩家扣血
- 防御：获得格挡
- 技能：施加状态/特殊效果
    │
    ▼
状态效果结算
- 燃烧/毒素等持续伤害
- 回合结束效果
- 持续时间减少
    │
    ▼
检查胜利/失败条件
    │
    ▼
返回玩家回合 或 战斗结束
```

**伤害计算流程**：
```
卡牌基础伤害
    │
    ▼
+ 状态加成
    │
    ▼
= 基础伤害
    │
    ▼
× 环境系数 (K_env)
    │
    ▼
= 环境修正伤害
    │
    ▼
× 暴击修正
    │
    ▼
= 暴击修正伤害
    │
    ▼
× 防御修正 (K_def)
    │
    ▼
= 最终伤害 (最低为 1)
```

### 12.6 结果界面与结算

**战斗结算界面**：
- 显示战斗结果（胜利/失败）
- 战斗统计（回合数、使用卡牌、造成伤害、受到伤害、暴击次数）
- 获得奖励（星尘、星核、卡牌选择）
- 三选一卡牌选择（如适用）

**奖励计算**：
```
星尘获取 = (普通敌人数量 × 25 + 精英数量 × 60 + BOSS 数量 × 150) 
           × K_difficulty × K_map × K_refine

星核获取 = (精英数量 × 8 + BOSS 数量 × 25) 
           × K_difficulty × K_map × K_refine
```

### 12.7 远征结束流程

**完成条件**：
| 条件 | 说明 |
|:---|:---|
| 击败 BOSS | 远征通关 |
| 玩家 HP≤0 | 远征失败 |
| 主动放弃 | 中途退出 |

**返回基地流程**：
1. 保存远征进度
2. 发放奖励（星尘、星核）
3. 更新统计（远征次数、通关次数）
4. 保存玩家数据
5. 切换场景到基地

**继续远征流程**：
1. 返回地图场景
2. 恢复远征状态
3. 继续移动
