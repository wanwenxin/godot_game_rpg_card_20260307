## 一、游戏简介

### 1.1 游戏概述

**弃刃从牌**是一款以中世纪到工业革命早期混合时代为背景的卡牌构筑 Roguelike 游戏。玩家扮演移动堡垒的指挥官，探索被虚空污染的荒野，收集资源，强化自身，揭开大灾变的真相。

### 1.2 核心特色

| 特色 | 说明 |
|:---|:---|
| **时代背景** | 中世纪到工业革命早期的混合时代，中西方文化结合，低魔设定 |
| **7 名角色** | 人类为主（6 名人类，1 名精灵），女性为主（5 名女性，2 名男性），中西方结合（东方 3 名，西方 4 名） |
| **21 个流派分支** | 每名角色拥有 3 个专属流派分支，共 21 个流派，体现差异化特色 |
| **7 级卡牌品级** | 从粗糙到神话，卡牌可升级强化 |
| **词条系统** | 33 个词条，分为通用/流派/属性三大类 |
| **6 张远征地图** | 从边境荒野到天空城，难度递增 |
| **环境系统** | 6 种环境类型，影响属性伤害 |
| **基地建设** | 7 大建筑，局外成长系统 |

## 二、世界观与背景

### 2.1 时代背景

世界处于魔法与机械交汇的转折点：
- 东方仍保留着传统王朝与宗门体系
- 西方已出现蒸汽机械与早期工业
- 魔法稀有且危险，属于"低魔"设定
- 冷兵器与早期火器并存

### 2.2 历史脉络

#### 大灾变前——双元纪元

**东方（天朝上国）**：
- 墨家机关术鼎盛，创造自动傀儡与机械城
- 道门占星术预测天象，指导国运
- 武林门派传承武艺与内功心法
- 炼金术士炼制丹药与法器

**西方（诸王国）**：
- 圣教骑士团守护信仰与正义
- 精灵族与自然和谐共存
- 蒸汽工匠公会兴起，机械技术萌芽
- 炼金公会研究元素与物质转化

#### 大灾变——虚空降临

**灾变原因**：东西方法师联合试图打开"原点之门"获取无限能量，虚空能量泄露，污染了世界，魔法平衡被打破，元素暴走。

**灾变影响**：
- 大陆破碎，形成荒野与隔离带
- 魔物横行，文明退居少数移动堡垒
- 魔法变得稀有且危险
- 古代遗迹散落各地，蕴含失落知识

#### 当前世界——新纪元 500 年

- 人类在移动堡垒中生存
- 冒险者探索荒野，收集古代遗物
- 虚空威胁仍在，但已减弱
- 新的势力正在崛起

### 4.4 属性词条（4 个）

| 词条 | 定义 | 环境影响 |
|:---|:---|:---|
| **燃烧** | 标签。火焰属性 | 受环境影响，伤害加成 -3 到 +3 |
| **冰冻** | 标签。冰霜属性 | 受环境影响，伤害加成 -3 到 +3 |
| **雷电** | 标签。雷电属性 | 受环境影响，伤害加成 -3 到 +3 |
| **浸湿** | 标签。水属性 | 受环境影响，伤害加成 -3 到 +3 |

**环境加成公式**：
```
最终伤害 = 卡牌基础伤害 + 环境加成值（-3 到 +3）

示例：
火焰冲击（基础 10 点伤害，【燃烧】）
- 高温环境：10 + 3 = 13 点伤害
- 雨天环境：10 - 2 = 8 点伤害
```

### 5.3 综合计算公式

#### 资源获取公式
```
星尘获取 = (普通敌人数量 × 250 + 精英数量 × 600 + BOSS 数量 × 1,500) 
           × K_difficulty × K_map × K_refine

星核获取 = (精英数量 × 80 + BOSS 数量 × 250) 
           × K_difficulty × K_map × K_refine
```

#### 伤害计算公式
```
基础伤害 = 卡牌基础值 + 状态加成
环境修正 = 基础伤害 × K_env
防御修正 = 环境修正 × K_def
最终伤害 = max(1, 防御修正)
```

#### 敌人强度公式
```
敌人实际 HP = 敌人基础 HP × K_difficulty × K_map
敌人实际攻击 = 敌人基础攻击 × K_difficulty × K_map
```

### 6.2 卡牌合成消耗（合卡操作）

**注意**：
- 卡牌合成仅在远征准备阶段进行，合成后的卡牌进入背包。远征时需用背包里的卡牌完成卡组构建。
- **锻造工坊的折扣仅作用于合卡操作，解锁卡牌消耗固定为基础值的 10 倍，不受折扣影响**。
- 每张卡牌合成只消耗一种资源（星尘 或 星核）。

### 9.2 合卡操作详解

**合卡含义**：在远征准备阶段，将额外卡牌（2-7 级）放入背包，用于本次远征。

**初始状态**：
- 卡组：空
- 背包：该角色所有 1 级卡（自动获得，无 cost，不占 cost 上限）

**合卡规则**：
| 规则 | 说明 |
|:---|:---|
| 可选卡牌 | 已解锁的 2-7 级卡牌（通用卡 + 角色专属卡） |
| cost 限制 | 本次远征带入的卡 cost 合计不得超过 cost 上限（初始 30，远征军部满级 60） |
| 资源消耗 | 2-4 级卡消耗星尘，5-7 级卡消耗星核 |
| 锻造折扣 | 锻造工坊等级提供 -3% 折扣，满级 -30% |
| 通用卡解锁 | 所有角色共享一个解锁进度 |
| 专属卡解锁 | 每个角色独立追踪解锁进度 |

**卡牌解锁条件**：
| 品级 | 解锁条件 |
|:---:|:---|
| 1 | 默认解锁 |
| 2-4 | 获得过 1 次 |
| 5-6 | 获得过 2 次 |
| 7 | 获得过 3 次 |

**直接解锁**：在炼金工房中可直接消耗资源解锁任意卡牌，消耗为合卡基础消耗的 10 倍，不受锻造工坊折扣影响。

### 10.2 状态切换触发条件

| 当前状态 | 目标状态 | 触发条件 | 数据传递 |
|:---|:---|:---|:---|
| BOOT | TITLE | 初始化完成 | 无 |
| TITLE | BASE | 点击继续游戏/新游戏 | 加载存档或创建新存档 |
| BASE | MAP_SELECT | 点击指挥中心 | 传递玩家当前资源 |
| MAP_SELECT | EXPEDITION | 确认地图和难度 | 传递 map_id, difficulty |
| EXPEDITION | BATTLE | 进入战斗节点 | 传递 enemy_config, environment |
| BATTLE | RESULT | 战斗结束（胜/负） | 传递 battle_result, rewards |
| RESULT | EXPEDITION | 继续远征 | 更新远征进度 |
| RESULT | BASE | 返回基地 | 保存远征进度，发放奖励 |
| EXPEDITION | GAME_OVER | 玩家 HP≤0 或通关 | 传递 final_result |

### 10.3 基地场景互动

**基地主界面**：
- 基地剖面背景
- 7 大建筑显示（锻造工坊、药剂师协会、战争学院、募兵所、精炼工厂、远征军部、炼金工房）
- 资源栏显示（星尘、星核、卡组数量、HP）
- 功能按钮（开始远征、调整卡组、查看收藏、成就、设置、退出）

**建筑升级流程**：
1. 点击建筑，打开升级界面
2. 显示当前等级、效果、升级消耗
3. 确认升级，扣除资源
4. 更新系数，保存数据
5. 返回基地主界面

### 10.4 远征地图场景

**地图加载与节点生成**：
1. 加载地图配置
2. 生成节点（10-15 个）
3. 连接路径
4. 绑定环境
5. 设置起点

**节点类型分布**：
| 节点类型 | 占比 | 说明 |
|:---|:---:|:---|
| 起点 | 固定 | 第 1 个节点，安全 |
| 战斗 | 50-60% | 普通敌人战斗 |
| 营地 | 10-15% | 安全屋，恢复 |
| 奖励 | 10-15% | 三选一奖励 |
| 事件 | 10-15% | 随机事件 |
| 精英 | 5-10% | 精英敌人 |
| BOSS | 固定 | 最后节点 |

**移动规则**：
- 每个节点通常连接 1-3 个后续节点
- 玩家只能移动到相邻节点
- 不能回头移动

### 10.5 战斗场景流程

**战斗初始化**：
1. 生成敌人
2. 设置环境
3. 初始化战斗数据
4. 构建卡组
5. 抽初始手牌（5 张）
6. 播放入场动画
7. 开始玩家回合

**回合制循环**：
```
玩家回合开始
    │
    ▼
1. 回合数 +1
2. 重置能量到最大值
3. 抽 3 张牌
4. 更新敌人意图显示
    │
    ▼
玩家行动阶段
- 使用卡牌（消耗能量）
- 卡牌效果即时结算
- 检查胜利条件
    │
    ▼
玩家点击「结束回合」
    │
    ▼
敌人回合开始
    │
    ▼
敌人行动阶段
- 攻击：计算伤害，玩家扣血
- 防御：获得格挡
- 技能：施加状态/特殊效果
    │
    ▼
状态效果结算
- 燃烧/毒素等持续伤害
- 回合结束效果
- 持续时间减少
    │
    ▼
检查胜利/失败条件
    │
    ▼
返回玩家回合 或 战斗结束
```

**伤害计算流程**：
```
卡牌基础伤害
    │
    ▼
+ 状态加成
    │
    ▼
= 基础伤害
    │
    ▼
× 环境系数 (K_env)
    │
    ▼
= 环境修正伤害
    │
    ▼
× 防御修正 (K_def)
    │
    ▼
= 最终伤害 (最低为 1)
```

### 10.6 结果界面与结算

**战斗结算界面**：
- 显示战斗结果（胜利/失败）
- 战斗统计（回合数、使用卡牌、造成伤害、受到伤害）
- 获得奖励（星尘、星核、卡牌选择）
- 三选一卡牌选择（如适用）

**奖励计算**：
```
星尘获取 = (普通敌人数量 × 250 + 精英数量 × 600 + BOSS 数量 × 1,500) 
           × K_difficulty × K_map × K_refine

星核获取 = (精英数量 × 80 + BOSS 数量 × 250) 
           × K_difficulty × K_map × K_refine
```

### 10.7 远征结束流程

**完成条件**：
| 条件 | 说明 |
|:---|:---|
| 击败 BOSS | 远征通关 |
| 玩家 HP≤0 | 远征失败 |
| 主动放弃 | 中途退出 |

**返回基地流程**：
1. 保存远征进度
2. 发放奖励（星尘、星核）
3. 更新统计（远征次数、通关次数）
4. 保存玩家数据
5. 切换场景到基地

**继续远征流程**：
1. 返回地图场景
2. 恢复远征状态
3. 继续移动

## 十三、核心数据结构

### 13.1 PlayerData（玩家数据）

```gdscript
class_name PlayerData extends RefCounted

# 基础信息
var player_id: String          # 玩家唯一 ID
var character_id: String       # 当前角色 ID
var character_data: Character  # 角色实例

# 资源
var stardust: int              # 星尘
var star_core: int             # 星核
var gold: int                  # 金币

# 解锁内容
var unlocked_characters: Array[String]  # 已解锁角色
var unlocked_cards: Dictionary          # 已解锁卡牌 {card_id: unlock_count}

# 卡牌解锁状态
var universal_cards_unlocked: Dictionary  # 通用卡解锁状态 {card_id: bool}
var character_cards_unlocked: Dictionary  # 角色专属卡解锁状态 {character_id: {card_id: unlock_count}}

# 收藏
var collected_cards: Array[CardInstance]  # 收藏卡牌
var collected_affixes: Array[String]      # 已解锁词条

# 成就
var achievements: Dictionary  # {achievement_id: completed}

# 统计
var stats: PlayerStats  # 游戏统计数据

# 当前远征
var current_expedition: ExpeditionData
```
