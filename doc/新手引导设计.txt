## 一、新手引导概述

### 1. 设计目标

新手引导帮助新玩家**循序渐进**地理解游戏复杂系统，避免信息过载，同时保持游戏沉浸感。

**核心原则**：
- 渐进式教学，不一次性灌输
- 边做边学，实践为主
- 可随时跳过/回顾
- 与剧情融合，保持沉浸感

### 2. 引导阶段划分

| 阶段 | 名称 | 触发时机 | 时长 |
|:---|:---|:---|:---|
| **阶段 1** | 初次接触 | 首次启动游戏 | 5 分钟 |
| **阶段 2** | 基地介绍 | 首次进入基地 | 5 分钟 |
| **阶段 3** | 战斗教学 | 首次战斗 | 10 分钟 |
| **阶段 4** | 环境系统 | 首次遭遇环境变化 | 5 分钟 |
| **阶段 5** | 消耗品系统 | 首次制造消耗品 | 5 分钟 |
| **阶段 6** | 进阶系统 | 首次解锁流派/成就 | 10 分钟 |

## 二、阶段 1：初次接触

### 1. 开场动画

**内容**：
```
1. 黑屏，文字："大灾变后 100 年..."
2. 荒凉大地远景
3. 移动基地缓缓驶过
4. 主角站在基地顶部眺望远方
5. 标题出现：《原点移动》
6. 点击任意位置继续
```

**时长**：30 秒（可跳过）

**界面**：全屏卡片轮播

**操作**：点击"下一步"或滑动切换

## 三、阶段 2：基地介绍

### 1. 基地初识

**触发**：首次进入基地

**引导流程**：
```
1. 镜头聚焦中央指挥部
   → 弹出提示："这是中央指挥部，点击升级"
   → 高亮建筑，显示红点

2. 玩家点击后
   → 展示升级界面
   → 引导升级（免费首次）
   → 提示："升级后 HP+50"

3. 镜头移至战略实验室
   → 提示："这里可以定制你的核心卡"

4. 镜头移至后勤制造厂
   → 提示："制造消耗品带入战斗"
```

### 2. 核心卡选择

**触发**：首次进入战略实验室

**引导内容**：
```
"选择你的核心卡作为起始卡组"

展示 3 张核心卡供选择：
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  雷霆核心   │  │  烈焰核心   │  │  动能核心   │
│  电系伤害   │  │  火系伤害   │  │  物理伤害   │
│  适合新手   │  │  中等难度   │  │  中等难度   │
│  [选择]     │  │  [选择]     │  │  [选择]     │
└─────────────┘  └─────────────┘  └─────────────┘
```

**设计说明**：
- 雷霆核心最简单，推荐新手
- 选择后解锁对应流派教学

## 四、阶段 3：战斗教学

### 1. 首次战斗（教学战）

**敌人**：流寇（简化版，HP 50）

**引导流程**：

```
回合 1：
1. 高亮抽牌区
   → "每回合自动抽 3 张牌"

2. 高亮能量区
   → "你有 3 点能量"

3. 高亮手牌中的"基础攻击"
   → "点击卡牌查看效果"
   
4. 玩家点击卡牌后
   → "拖动卡牌到敌人身上释放"
   → 或 "点击卡牌，再点击敌人"

5. 玩家释放后
   → "造成 10 点伤害！"
   → 显示伤害数字

6. 敌人回合
   → "敌人要攻击了！"
   → 显示敌人意图图标

7. 玩家受到伤害
   → "注意你的生命值"
```

### 2. 进阶教学

**第二回合**：
```
1. 抽到"能量冲击"
   → "这张牌消耗 2 点能量"
   → "你的能量不够！"
   → "等待下回合或先使用低消耗牌"

2. 抽到"格挡"
   → "格挡可以抵挡下次攻击"
   → "在敌人攻击前使用"
```

### 3. 战斗胜利

```
"胜利！"
→ 展示奖励界面
→ "获得金币×20，矿石×10"
→ "继续远征或返回基地"
```

## 八、引导 UI 设计

### 1. 提示框样式

```
┌─────────────────────────────────────────────────────────────┐
│  💡 提示                                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  这里是提示内容                                             │
│  可以有多行文字                                             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                              [知道了]  [不再显示]           │
└─────────────────────────────────────────────────────────────┘
```

**样式规范**：
- 背景：深色半透明 (#1A1A2EAA)
- 边框：琥珀色 (#FFB800)
- 文字：白色
- 图标：灯泡图标

### 2. 高亮样式

```
- 目标物体：发光效果 (Glow)
- 颜色：琥珀色脉冲
- 强度：0.5-1.0 循环
- 箭头指示：指向目标
```

### 3. 遮罩引导

```
- 屏幕变暗 (Alpha 0.7)
- 仅高亮区域可见
- 点击非高亮区域提示"点这里"
```

## 九、Godot 实现方案

### 1. 引导管理器

```gdscript
# TutorialManager.gd - 单例
class_name TutorialManager extends Node

signal tutorial_step_completed(step_id: String)
signal tutorial_section_completed(section_id: String)

var completed_steps: Array[String] = []
var current_tutorial: String = ""
var tutorial_data: Dictionary = {}

func _ready():
    load_tutorial_data()
    load_progress()

func start_tutorial(tutorial_id: String):
    current_tutorial = tutorial_id
    var tutorial = tutorial_data[tutorial_id]
    show_step(tutorial.steps[0])

func show_step(step_id: String):
    var step = get_step_data(step_id)
    
    # 高亮目标
    if step.has("highlight_target"):
        highlight_node(step.highlight_target)
    
    # 显示提示
    show_hint(step.text)
    
    # 等待条件
    if step.has("wait_condition"):
        await wait_for_condition(step.wait_condition)
    
    # 完成步骤
    complete_step(step_id)

func highlight_node(node_path: String):
    var node = get_node_or_null(node_path)
    if node:
        # 添加高亮效果
        var highlight = HighlightEffect.new()
        node.add_child(highlight)

func show_hint(text: String):
    hint_popup.show_text(text)

func complete_step(step_id: String):
    if step_id not in completed_steps:
        completed_steps.append(step_id)
        tutorial_step_completed.emit(step_id)
        save_progress()
```

### 3. 提示系统

```gdscript
# HintPopup.gd
class_name HintPopup extends PanelContainer

@onready var label: Label = $VBoxContainer/Label
@onready var confirm_button: Button = $VBoxContainer/ConfirmButton

var on_confirm: Callable = func(): pass

func _ready():
    confirm_button.pressed.connect(_on_confirm)
    hide()

func show_text(text: String, on_confirm_callback: Callable = func(): pass):
    label.text = text
    on_confirm = on_confirm_callback
    show()
    animate_in()

func _on_confirm():
    animate_out()
    await get_tree().create_timer(0.3).timeout
    on_confirm.call()
```

## 十、引导跳过与回顾

### 1. 跳过机制

- 每个引导步骤都有"跳过"按钮
- 长按 3 秒可跳过整个引导
- 跳过后可在帮助中回顾

### 2. 帮助系统

**帮助入口**：
- 基地：右上角问号按钮
- 战斗：暂停菜单中的"帮助"

**帮助内容**：
```
┌─────────────────────────────────────────────────────────────┐
│  帮助中心                                      [X]          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📖 基础规则                                                │
│  ⚔️ 战斗系统                                                │
│  🌍 环境系统                                                │
│  🧪 消耗品系统                                              │
│  🏗️ 基地系统                                                │
│  🎯 成就系统                                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3. 回顾触发

- 玩家可主动点击"回顾"重新观看引导
- 首次遇到新系统时自动触发
- 连续失败 3 次后提示"需要帮助吗？"
