## 一、音效设计风格

### 1. 整体风格定义

**风格名称**：末世工业科幻氛围

- **核心理念**：荒凉中的科技感，压抑中的希望
- **听觉关键词**：低沉、机械、电子、环境音
- **音色基调**：低频为主，合成器音色，金属质感

### 2. 音频技术规格

| 参数 | 规格 |
|:---|:---|
| **BGM 格式** | OGG Vorbis (128kbps) |
| **SFX 格式** | WAV (44.1kHz/16bit) |
| **音量标准** | BGM: -18dB, SFX: -6dB, UI: -3dB |
| **循环点** | 无缝循环，标记 In/Out 点 |
| **声道** | BGM 立体声，SFX 单声道 |

### 3. Godot 音频总线配置

```gdscript
# AudioBusLayout.tres 配置
 buses: [
   { "name": "Master", "channels": 2 },
   { "name": "BGM", "send": "Master", "volume_db": -5 },
   { "name": "SFX", "send": "Master", "volume_db": 0 },
   { "name": "UI", "send": "Master", "volume_db": 3 },
   { "name": "Ambience", "send": "Master", "volume_db": -10 }
 ]
```

## 四、音频实现方案 (Godot)

### 1. 音频管理器

```gdscript
# AudioManager.gd - 单例
class_name AudioManager extends Node

@onready var bgm_player: AudioStreamPlayer = $BGMPlayer
@onready var sfx_bus: AudioStreamPlayer = $SFXBus
@onready var ambience_player: AudioStreamPlayer = $AmbiencePlayer

var bgm_library: Dictionary = {}
var sfx_library: Dictionary = {}

func _ready():
    # 预加载所有音频
    preload_bgm()
    preload_sfx()

func play_bgm(track_name: String, fade_in: float = 1.0):
    if bgm_library.has(track_name):
        var tween = create_tween()
        tween.tween_property(bgm_player, "volume_db", -80, 0.5)  # 淡出当前
        bgm_player.stream = bgm_library[track_name]
        bgm_player.play()
        tween.tween_property(bgm_player, "volume_db", -5, fade_in)  # 淡入新曲

func play_sfx(sfx_name: String, pitch_variance: float = 0.0):
    if sfx_library.has(sfx_name):
        sfx_bus.stream = sfx_library[sfx_name]
        if pitch_variance > 0:
            sfx_bus.pitch_scale = randf_range(1.0 - pitch_variance, 1.0 + pitch_variance)
        sfx_bus.play()

func set_bus_volume(bus_name: String, volume_db: float):
    var bus_idx = AudioServer.get_bus_index(bus_name)
    if bus_idx >= 0:
        AudioServer.set_bus_volume_db(bus_idx, volume_db)
```

### 2. 动态音乐切换

```gdscript
# 根据战斗状态切换 BGM
func update_battle_music():
    if BattleManager.is_boss_fight:
        AudioManager.play_bgm("boss_phase1")
    elif BattleManager.is_elite:
        AudioManager.play_bgm("battle_elite")
    else:
        AudioManager.play_bgm("battle_normal")
```

### 3. 环境音效混合

```gdscript
# 根据环境类型播放对应环境音
func set_environment_sound(env_type: String):
    var env_sound_map = {
        "sunny": "",
        "rain": "env_rain",
        "storm": "env_storm",
        "hot": "env_heat",
        "cold": "env_cold",
        "poison": "env_poison",
        "gravity": "env_gravity"
    }
    
    if env_sound_map.has(env_type) and env_sound_map[env_type] != "":
        ambience_player.stream = load("res://assets/audio/ambience/" + env_sound_map[env_type] + ".ogg")
        ambience_player.play()
```

### 4. 音效池 (避免重叠)

```gdscript
# 对于频繁播放的音效，使用池管理
var sfx_pool: Array[AudioStreamPlayer] = []

func get_sfx_player() -> AudioStreamPlayer:
    for player in sfx_pool:
        if not player.playing:
            return player
    
    # 池中没有可用播放器，创建新的
    var new_player = AudioStreamPlayer.new()
    new_player.bus = "SFX"
    add_child(new_player)
    sfx_pool.append(new_player)
    return new_player
```

## 六、音频制作优先级

### P0 - 核心音频（首版本必须）

1. 基地 BGM (1 首)
2. 普通战斗 BGM (1 首)
