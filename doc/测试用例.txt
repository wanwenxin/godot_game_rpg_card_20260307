## 一、测试概述

### 1. 测试目标

确保游戏各系统功能正常，性能达标，玩家体验流畅。

**测试类型**：
| 类型 | 说明 | 执行时机 |
|:---|:---|:---|
| 功能测试 | 验证各系统功能 | 开发阶段 |
| 性能测试 | 帧率、内存、加载时间 | 开发阶段/发布前 |
| 兼容性测试 | 不同分辨率/设备 | 发布前 |
| 回归测试 | 修复后验证 | 每次修改后 |
| 用户测试 | 真实玩家体验 | Beta 阶段 |

### 2. 测试环境

| 平台 | 最低配置 | 推荐配置 |
|:---|:---|:---|
| Windows | Win10, 4GB RAM, GTX 750 | Win11, 8GB RAM, GTX 1060 |
| macOS | macOS 10.14, 4GB RAM | macOS 12+, 8GB RAM |
| Linux | Ubuntu 20.04, 4GB RAM | Ubuntu 22.04, 8GB RAM |

## 六、Godot 测试实现

### 1. 单元测试框架

```gdscript
# test_battle_system.gd
extends GUTTest

func test_draw_card():
    var battle = BattleManager.new()
    battle.start_battle()
    
    var hand_size = battle.get_hand_size()
    assert_eq(hand_size, 5, "初始手牌应为 5 张")
    
    battle.draw_cards(3)
    hand_size = battle.get_hand_size()
    assert_eq(hand_size, 8, "抽 3 张后手牌应为 8 张")

func test_energy_reset():
    var battle = BattleManager.new()
    battle.set_energy(1)
    battle.end_turn()
    
    var energy = battle.get_energy()
    assert_eq(energy, 3, "回合开始能量应重置为 3")
```

### 2. 性能监控

```gdscript
# PerformanceMonitor.gd
class_name PerformanceMonitor extends Node

var fps_history: Array[float] = []
var memory_samples: Array[int] = []

func _process(_delta):
    # 记录帧率
    var fps = Performance.get_monitor(Performance.TIME_FPS)
    fps_history.append(fps)
    if fps_history.size() > 60:
        fps_history.pop_front()
    
    # 记录内存
    var mem = Performance.get_monitor(Performance.MEMORY_STATIC)
    memory_samples.append(int(mem))
    if memory_samples.size() > 60:
        memory_samples.pop_front()

func get_average_fps() -> float:
    if fps_history.is_empty():
        return 0.0
    return sum(fps_history) / fps_history.size()

func get_current_memory_mb() -> float:
    if memory_samples.is_empty():
        return 0.0
    return memory_samples[-1] / 1048576.0
```

### 3. 自动化测试脚本

```bash
#!/bin/bash

    exit 1
fi
```

## 八、Bug 追踪流程

```
发现 Bug → 记录 Bug → 分配修复 → 修复完成 → 回归测试 → 关闭 Bug
```

### Bug 优先级

| 优先级 | 说明 | 响应时间 |
|:---|:---|:---|
| P0 - 严重 | 游戏崩溃/存档损坏 | 24 小时内 |
| P1 - 高 | 核心功能失效 | 3 天内 |
| P2 - 中 | 功能异常但有 workaround | 1 周内 |
| P3 - 低 | UI 问题/拼写错误 | 下个版本 |
