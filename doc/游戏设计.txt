# 游戏设计方案书：项目代号《原点移动 (Mobile Core)》

**版本**：3.0  
**最后更新**：2026-03-11  
**游戏引擎**：Godot 4.6  
**游戏类型**：基地经营 + 类搜打撤 + 环境博弈卡牌

---

## 一、核心玩法概述

本作为单机卡牌构筑游戏。玩家扮演移动基地的指挥官，在资源匮乏的荒野中进行**远征（Run）**。通过**卡牌战斗**获取资源，在**局外建设基地**，利用**卡牌品级构筑**与**环境交互**，最终实现数值破格的爽快战斗。

### 核心循环：搜打撤

| 阶段 | 内容 | 目标 |
|:---|:---|:---|
| **搜 (Search)** | 远征地图探索、节点选择、情报收集 | 获取资源、解锁卡牌 |
| **打 (Fight)** | 卡牌战斗、卡组构筑、状态博弈 | 击败敌人、获得掉落 |
| **撤 (Extract)** | 撤离结算、资源带回、基地升级 | 强化自身、解锁新内容 |

## 二、系统架构图与关系说明

### 1. 系统关系链

* **基地 (Meta) → 战斗 (Run)：** 提供可带入的卡牌（消耗资源生成）、角色技能选择、复活次数。
* **战斗 (Run) → 基地 (Meta)：** 带回资源（低级/高级），用于升级建筑、解锁卡牌、生成带入卡牌。
* **环境 (Environment) ↔ 卡牌 (Card)：** 环境修正卡牌数值；卡牌/消耗品可强行改变环境。
* **状态 (Status) → 终结 (Finish)：** 状态叠层触发生命值溢出的"机制杀"，获取隐藏奖励。
* **角色 (Character) → 卡牌 (Card)：** 不同角色使用不同的卡牌池，拥有独立技能。

### 2. 卡牌品级系统

| 品级 | 名称 | 颜色 | 解锁条件 | 资源类型 |
|:---:|:---|:---|:---|:---|
| 1 | **粗糙** | ⚪ 白 | 默认解锁 | 低级 |
| 2 | **普通** | 🟢 绿 | 获取 1 次 | 低级 |
| 3 | **精良** | 🔵 蓝 | 获取 1 次 | 低级 |
| 4 | **卓越** | 🟣 紫 | 获取 2 次 | 低级 |
| 5 | **史诗** | 🟠 橙 | 获取 2 次 | 高级 |
| 6 | **传说** | 🔴 红 | 获取 3 次 | 高级 |
| 7 | **神话** | 🟡 金 | 获取 3 次 | 高级 |

**解锁规则**：
- 1 级卡牌默认全解锁
- 2-3 级卡牌：远征内获取 1 次后解锁
- 4-5 级卡牌：远征内获取 2 次后解锁
- 6-7 级卡牌：远征内获取 3 次后解锁

**魔法图书馆解锁**：已获得至少 1 次的卡牌，可消耗资源直接解锁剩余次数
- 消耗公式：`消耗资源数 = 卡牌品级 × 剩余解锁次数 × 基础系数`

### 3. 卡牌与词条系统

**卡牌系统**：
- 默认卡牌不带词条
- 卡牌效果由品级决定，品级越高效果越强
- 同一张卡牌可存在多个品级版本

**词条系统**（独立）：
- 词条与卡牌是两套独立系统，可自由组合
- 通过附加词条改变卡牌强弱

| 词条类型 | 效果 | 品级影响 |
|:---|:---|:---|
| 一场战斗限用一次 | 限制使用次数 | 降低品级需求 |
| 第一回合自动获取 | 开局自动加入手牌 | 提高品级需求 |
| 需要元素充能 | 需要特定元素层数 | 降低品级需求 |
| 击杀后返还消耗 | 击杀敌人返还能量 | 提高品级需求 |
| 需要蓄力回合 | 需要等待回合 | 降低品级需求 |
| 可保留至下回合 | 使用后不消失 | 提高品级需求 |

## 三、局外：基地系统 (The Base)

### 1. 七大建筑功能

| 建筑名称 | 功能描述 | 升级效果 |
|:---|:---|:---|
| **远征者大厅** | 远征选择、角色管理、技能解锁 | 解锁更多角色技能、提高免费资源额度 |
| **符文锻造台** | 消耗资源生成带入远征的卡牌 | 提高免费额度、提高各品级数量上限 |
| **炼金转化阵** | 低级资源↔高级资源转换 | 提高转换效率（减少损耗） |
| **遗物保管库** | 扩展各品级卡牌数量上下限 | 每级扩大不同品级的上下限 |
| **生命圣坛** | 提升复活次数上限 | 初始 0 次，每级 +1 次，最高 3 次 |
| **知识圣殿** | 卡牌图鉴、收集进度、成就展示 | 解锁"展示未获得卡"功能、追踪收集进度 |
| **魔法图书馆** | 局内查看情报/图鉴/卡牌，消耗资源解锁卡牌 | 升级后可直接消耗资源解锁当前阶级未获得的卡牌 |

### 2. UI 设计风格：**【中世纪奇幻控制台风格】**

* **布局：** 采用**侧剖面图**展示基地建筑（移动堡垒内部）。
* **交互：** 点击建筑进入各功能区域。
* **视觉：** 深色底背景配以高亮的琥珀色或淡蓝色文字，中世纪工业风格。
* **建筑反馈：** 升级建筑时，建筑模型会有视觉上的扩张感。

## 四、局内：战斗与构筑系统 (The Run)

### 1. 远征前准备

**角色选择**：
- 不同角色使用不同的卡牌池
- 可生成的卡牌和掉落卡牌因角色而异
- 每个角色可预设最多 3 套卡组（可重复使用）

**角色技能**（远征前选择）：
- 检索型：完成目标后稳定检索指定卡牌
- 生成型：每次攻击后概率生成 1 级攻击卡
- 增益型：特定条件下获得额外能量
- 防御型：概率格挡或减少伤害

**卡牌带入**：
- 免费额度 + 消耗资源 = 可带入卡牌
- 免费额度通过基地建设提升
- 消耗资源根据卡牌品级：
  - 1-3 级卡牌：消耗低级资源
  - 4-5 级卡牌：消耗低级资源（高品级）
  - 6-7 级卡牌：消耗高级资源
- 带入数量限制：
  - 总额度限制
  - 各品级独立额度限制
  - 通过基地建设提高限制数量

**情报系统**：
- 战斗前可查看敌人和场地情报
- 针对性选择卡组和调整构筑

### 2. 卡组与背包

| 系统 | 内容 | 规则 |
|:---|:---|:---|
| **卡组** | 玩家当局构筑的卡牌 | 仅包含玩家选择的卡，不可放入背包里没有的卡 |
| **背包** | 带入的卡牌 + 所有 1 级卡 + 战斗后获得的卡 | 所有卡必须是当前角色可使用的 |

**卡组调整**：
- 远征期间可随时调整卡组
- 每个品级有数量上下限
- 通过遗物保管库扩展各品级上下限

**卡牌叠放**：
- 同名、同品级卡牌自动叠放
- 右下角显示叠放数量

### 3. 战斗规则

* **卡组容量：** 20-40 张。支持预设多个卡组模板。
* **环境层：** 战场上方显示当前环境图标（如：暴雨、高重力）。
* **状态叠层：** 伤害公式采用 `伤害 = (基础 + 状态加成) × 环境倍率 × 暴击倍率`。
* **机制杀：** 使用特定属性或超大额伤害击杀 BOSS，触发全屏慢动作与隐藏掉落。

## 五、资源系统

### 1. 资源类型

| 资源 | 用途 | 获取方式 |
|:---|:---|:---|
| **低级资源** | 1-5 级卡牌生成、建筑升级、资源转换 | 远征完成（任意节点） |
| **高级资源** | 6-7 级卡牌生成、高级建筑升级、资源转换 | 远征完成（精英/BOSS 节点） |

### 2. 资源消耗途径

| 用途 | 消耗资源类型 | 说明 |
|:---|:---|:---|
| 生成带入卡牌 | 低/高级资源 | 根据品级消耗不同资源 |
| 建筑升级 | 低/高级资源 | 7 大建筑升级 |
| 资源转换 | 低级资源 | 转换为高级资源（有损耗） |
| 角色解锁 | 高级资源 | 解锁新角色 |
| 技能解锁 | 低/高级资源 | 解锁新角色技能 |
| 卡组预设位 | 低级资源 | 解锁额外卡组预设位（初始 3 个） |
| 卡牌解锁 | 低/高级资源 | 魔法图书馆直接解锁卡牌 |
| 卡牌分解 | 无（获得资源） | 分解多余卡牌获得资源 |
| 遗迹探索 | 低级资源 | 派遣探索队获得随机资源 |
| 情报查看 | 低级资源 | 魔法图书馆查看敌人详细数据 |
| 存档扩展 | 高级资源 | 扩展存档位（5→10） |

### 3. 资源获取与带回

**远征内不再获得局内可用资源**，所有资源仅在局外（基地）消耗。

| 撤离类型 | 触发条件 | 收益 |
|:---|:---|:---|
| 紧急撤离 | 任意战斗节点后 | 带回 50% 资源 |
| 计划撤离 | 安全屋使用撤离装置 | 带回 80% 资源 |
| 胜利撤离 | 击败 BOSS 后 | 带回 100% 资源 + 额外奖励 |
| 完美撤离 | 无死亡 + 回合达标 + 机制杀 | 带回 120% 资源 + 稀有蓝图 |
| 失败撤离 | 战败且无复活 | 带回 30% 资源 |

## 六、战斗与掉落系统

### 1. 卡牌获取机制

- **移除商店系统**
- 打怪掉落采用 **9 选 3** 机制
- 怪物等级越高，掉落卡牌越强
- 所有掉落卡牌必须是当前角色可使用的

### 2. 卡牌筛选功能

**适用位置**：卡组、背包、图鉴等所有查看卡牌的地方

**筛选条件**：
- 品级（1-7 级）
- 词条（附加效果）
- 卡牌类型（攻击/防御/技能等）
- 使用角色
- 卡牌名称

**排序功能**：支持按上述条件排序

**显示选项**：可勾选"展示当前没有的卡"（卡组中不可展示）

---

## 七、复活与失败机制

| 状态 | 规则 |
|:---|:---|
| **复活次数** | 初始 0 次，最高 3 次（通过生命圣坛提升） |
| **复活生效** | 累计复活次数，本局游戏内有效 |
| **战败复活** | 消耗 1 次复活机会，恢复一定生命 |
| **放弃复活** | 复活界面可主动放弃，算作失败 |
| **无复活战败** | 仅保留 30% 资源 |
| **主动放弃** | 远征地图上可主动放弃，算作失败 |

---

## 八、存档系统

| 规则 | 说明 |
|:---|:---|
| 存档数量 | 默认 5 个存档位（可通过魔法图书馆扩展至 10 个） |
| 手动保存 | 不允许 |
| 自动保存 | 远征进入新节点时、基地每次操作后 |
| 资源独立 | 存档之间资源独立 |
| 卡牌解锁独立 | 各存档已解锁卡牌独立 |

## 九、远征地图

### 1. 地图布局

* **横向卷轴布局：** 地图从左往右延伸，共 6 列，每列 2-3 个节点，提供多路径选择。
* **节点标注：** 清晰标注节点类型（战斗/精英/事件/安全屋/BOSS/隐藏）。
* **列指示器：** 地图上方显示当前列数（如"第 3 列/共 6 列"）和资源倍率。
* **资源倍率显示：** 每个节点显示资源获取倍率（1.0x → 5.0x 递增）。

### 2. 节点类型

| 节点 | 图标 | 说明 |
|:---|:---:|:---|
| 战斗 | ⚔️ | 普通战斗，资源倍率 1.0x-1.5x |
| 精英 | 💀 | 强化敌人，资源倍率 1.5x-2.0x |
| 事件 | ❓ | 随机事件，可能获得资源或卡牌 |
| 安全屋 | 🏠 | 休息、调整、制造 |
| BOSS | 👹 | 区域 BOSS，资源倍率 3.0x+ |
| 隐藏 | ⭐ | 隐藏节点，资源倍率 3.0x-5.0x |

### 3. 自动保存点

- 每进入一个新节点时自动保存
- 基地界面每次操作后自动保存

## 十、成长曲线与数值节奏

1. **时长控制：**
   - 前期关卡（第 1-3 列）：敌人血薄，单场 2 分钟
   - 中期关卡（第 4 列）：敌人强度提升，单场 3-5 分钟
   - 后期关卡（第 5-6 列）：敌人血量高，单场 5-7 分钟
   - BOSS 战：多阶段血条，单场 5-10 分钟
   - 远征总时长：2.5-3 小时（15-18 个节点，10-12 场战斗）

2. **资源递增机制：**
   - 前期（第 1-2 列）：资源倍率 1.0x，稀有掉落率 5%
   - 中期（第 3-4 列）：资源倍率 1.2x-1.5x，稀有掉落率 10%-15%
   - 后期（第 5-6 列）：资源倍率 2.0x-2.5x，稀有掉落率 20%-25%
   - BOSS 节点：资源倍率 3.0x+，稀有掉落率 35%+
   - 隐藏节点：资源倍率 3.0x-5.0x，稀有掉落率 40%

3. **爽点保证：**
   - 保证玩家在经营成型后，单局内至少能实现一次"指数级膨胀"
   - 后期高资源倍率战斗提供爽快感
   - 完美撤离获得 120% 资源 + 稀有蓝图
