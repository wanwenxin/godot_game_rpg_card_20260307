## 一、美术风格概述

### 1. 整体风格

**风格名称**：中世纪工业/科幻混合

- **核心理念**：末世废土中的古代科技遗迹
- **视觉关键词**：粗犷、功能化、神秘、科技感
- **色彩基调**：深色背景 + 琥珀色/淡蓝色高亮

### 2. 色彩规范

| 用途 | 颜色 | 色值 |
|:---|:---|:---|
| 主背景 | 深空蓝黑 | #1A1A2E |
| 次要背景 | 深灰色 | #2D2D3A |
| 主色调 | 琥珀色 | #FFB800 |
| 辅助色 | 淡蓝色 | #00D4FF |
| 强调色 | 赤红色 | #FF4444 |
| 文字色 | 纯白 | #FFFFFF |
| 次要文字 | 浅灰 | #AAAAAA |
| 禁用色 | 深灰 | #666666 |

### 3. 通用规范

- **线条风格**：2px 描边，硬朗边缘
- **光影**：定向光源（左上 45°）
- **粒子效果**：适度使用，不遮挡关键信息

## 十、技术规格

### 1. 图片格式

- **主要格式**：PNG（支持透明通道）
- **压缩**：无损压缩
- **色深**：32 位（RGBA8888）

### 2. 纹理图集

- 使用 Godot 的 `TexturePacker` 或类似工具
- 最大图集尺寸：4096x4096
- 边距：2px
- 出血：1px

### 3. 9 宫格资源

- 用于可拉伸的 UI 元素
- 标注切割线位置
- 中心区域用于拉伸

### 4. 动画资源

- **帧率**：30 FPS 或 60 FPS
- **格式**：序列帧 PNG
- **命名**：`{资源名}_{动作}_{帧号}.png`
