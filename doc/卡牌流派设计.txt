# 卡牌流派设计文档

**版本**：1.0  
**最后更新**：2026-03-09  
**说明**：本文档为《原点移动 (Mobile Core)》的核心卡牌设计参考，所有卡牌数值和效果均以此为准。

---

## 一、基础系统规则

### 1. 能量系统
- **基础能量**：3 点/回合
- **能量上限**：可通过核心卡/天赋提升至 5-7 点
- **能量不结转**：回合结束清空

### 2. 卡牌类型
| 类型 | 标识 | 说明 |
|:---|:---|:---|
| 核心卡 | CORE | 流派专属，开局必上手 |
| 技能卡 | SKILL | 通用效果，可跨流派 |
| 攻击卡 | ATTACK | 造成伤害 |
| 状态卡 | STATUS | 施加状态 |
| 消耗卡 | CONSUME | 使用后进入冷却 |

### 3. 抽牌规则
- 初始手牌：5 张
- 每回合抽牌：3 张
- 弃牌堆循环：卡组抽完后自动洗牌

### 4. 多语言键位预留
所有卡牌名称和描述使用键位格式：
- 名称键：`card.{卡牌标识}.name`
- 描述键：`card.{卡牌标识}.desc`

## 六、组合效果提示规则

游戏内需内置提示系统：

### 1. 手牌提示
- 当手牌中有可触发连招的卡牌时，卡牌边缘发光
- 颜色规则：
  - 绿色：连招准备中
  - 金色：连招可完成
  - 红色：机制杀可触发

### 2. 状态提示
- 状态即将叠满时（≥80%），状态图标闪烁
- 状态叠满时，播放特殊动画

### 3. 组合提示
- 拥有组合卡牌时，在卡组界面显示组合名称
- 组合激活时，显示激活动画

### 4. 提示文案格式

```
连招提示：已准备 [雷暴终结] 的前 3 步
状态预警：[毒素] 还需 3 层触发机制杀
组合激活：[元素大师] 已激活，环境卡消耗 -1
机制杀就绪：[毒发身亡] 可触发
```

### 5. 提示多语言键

```
tip.combo.ready = "连招提示：已准备 [{0}] 的前 {1} 步"
tip.status.warning = "状态预警：[{0}] 还需 {1} 层触发机制杀"
tip.set.activated = "组合激活：[{0}] 已激活，{1}"
tip.mechanic.ready = "机制杀就绪：[{0}] 可触发"
```
