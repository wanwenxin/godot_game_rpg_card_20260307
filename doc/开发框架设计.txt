**版本**：1.0  
**最后更新**：2026-03-10  
**游戏引擎**：Godot 4.6  
**关联文档**：开发细节.txt、UI 设计文档.txt、游戏设计.txt

---

## 一、框架概述

### 1.1 设计目标

本框架专为 RPG 卡牌 Roguelike 游戏设计，旨在提供：
- **高可维护性**：清晰的代码组织和架构分层
- **高可扩展性**：便于后续内容迭代和功能扩展
- **高性能**：针对 Godot 4.6 优化的最佳实践
- **数据驱动**：配置数据与逻辑代码完全分离

### 1.2 核心设计原则

| 原则 | 说明 | 实现方式 |
|:---|:---|:---|
| **数据驱动** | 游戏配置数据与逻辑分离 | Resource 资源文件 (.tres) |
| **事件驱动** | 模块间松耦合通信 | 信号总线 (EventBus) |
| **组件化** | 功能可复用、可替换 | 组件模式 + 场景组合 |
| **单例服务** | 全局服务统一管理 | Autoload 单例 |
| **对象池** | 性能优化 | 预实例化 + 池化复用 |

## 二、分层架构设计

### 2.1 架构分层图

```
┌─────────────────────────────────────────────────────────────┐
│                    Presentation Layer                       │
│  (UI/Visual) - CanvasLayer, Control, Animation, Shader      │
│  职责：用户界面展示、视觉反馈、输入处理                      │
├─────────────────────────────────────────────────────────────┤
│                    Game Logic Layer                         │
│  (Battle/Base/Map) - GameManager, BattleSystem, BaseSystem  │
│  职责：游戏规则、战斗逻辑、状态管理                          │
├─────────────────────────────────────────────────────────────┤
│                    Data Layer                               │
│  (Resources) - CardResource, EnvironmentResource, SaveData  │
│  职责：数据存储、配置管理、序列化                            │
├─────────────────────────────────────────────────────────────┤
│                    Core Services Layer                      │
│  (Singletons) - EventBus, ResourceManager, AudioManager     │
│  职责：全局服务、跨模块通信、资源管理                        │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 各层职责说明

#### Presentation Layer（表现层）
- UI 界面渲染和交互
- 动画和特效播放
- 音效和音乐播放
- 输入事件捕获

#### Game Logic Layer（游戏逻辑层）
- 战斗流程控制
- 卡牌效果执行
- 基地建设和管理
- 地图探索逻辑

#### Data Layer（数据层）
- 卡牌数据定义
- 敌人配置数据
- 环境效果数据
- 存档数据结构

#### Core Services Layer（核心服务层）
- 全局事件总线
- 资源加载管理
- 音频播放管理
- 存档读写管理

## 四、核心单例服务设计

### 4.1 GameEvents.gd - 信号总线

**职责**：全局事件中转站，实现模块间松耦合通信

**信号分类**：

| 分类 | 信号名 | 参数 | 说明 |
|:---|:---|:---|:---|
| **游戏状态** | game_state_changed | state: GameState | 游戏状态切换 |
| **战斗事件** | battle_started | enemy_data: Dictionary | 战斗开始 |
| | battle_ended | victory: bool, rewards: Dictionary | 战斗结束 |
| | card_played | card: CardResource, target: Entity | 卡牌打出 |
| | damage_dealt | source, target, amount, is_crit | 伤害造成 |
| | entity_died | entity: Entity | 实体死亡 |
| **环境事件** | environment_changed | env_type: String | 环境切换 |
| | weather_updated | weather: String | 天气更新 |
| **基地事件** | building_upgraded | building_id, new_level | 建筑升级 |
| | resource_changed | resource_type, new_amount | 资源变化 |
| | expedition_started | map_id, difficulty | 远征开始 |
| | expedition_ended | rewards: Dictionary | 远征结束 |
| **UI 事件** | ui_request_open | ui_name, data: Dictionary | 打开 UI |
| | ui_request_close | ui_name | 关闭 UI |
| | tooltip_request | text, position | 显示提示 |

---

### 4.2 GameManager.gd - 游戏管理器

**职责**：管理游戏全局状态、流程控制

**核心功能**：
- 游戏状态管理（MENU、BASE、MAP、BATTLE、PAUSE、GAME_OVER）
- 场景切换协调
- 全局数据访问接口
- 游戏流程控制

**状态流转**：
```
MENU → BASE → MAP → BATTLE → (胜利) → MAP → BASE
                          → (失败) → BASE → GAME_OVER
```

---

### 4.3 ResourceManager.gd - 资源管理器

**职责**：统一资源加载、缓存、卸载

**核心功能**：
- 资源预加载（Loading 场景）
- 资源缓存（避免重复加载）
- 资源卸载（释放内存）
- 异步加载支持

**资源类型**：
- Texture2D（纹理）
- PackedScene（场景）
- Resource（数据资源）
- AudioStream（音频）

---

### 4.4 AudioManager.gd - 音频管理器

**职责**：统一音频播放管理

**核心功能**：
- BGM 播放（支持淡入淡出、循环）
- SFX 播放（支持音量、音调控制）
- 音频设置（主音量、BGM 音量、SFX 音量）
- 音频池（复用 AudioStreamPlayer）

---

### 4.5 SaveManager.gd - 保存管理器

**职责**：游戏存档读写、加密、备份

**核心功能**：
- 存档序列化/反序列化
- 数据加密（防止篡改）
- 自动备份（防止存档损坏）
- 多存档位支持

**存档数据结构**：
- player_data（玩家数据）
- building_data（建筑数据）
- resource_data（资源数据）
- vault_cards（仓库卡牌）
- unlocks（解锁内容）
- achievements（成就）
- statistics（统计）

---

### 4.6 UIManager.gd - UI 管理器

**职责**：统一 UI 打开/关闭管理

**核心功能**：
- UI 实例管理（避免重复打开）
- UI 层级管理（Z-order）
- UI 动画统一处理
- UI 主题统一应用

---

### 4.7 ObjectPool.gd - 对象池

**职责**：高频对象复用，减少实例化开销

**管理对象**：
- 伤害飘字
- 打击特效
- 元素特效
- 卡牌（手牌区）

**池化策略**：
- 固定大小池（预分配）
- 动态扩展池（按需创建）
- 自动回收（生命周期结束）

## 五、Resource 数据驱动设计

### 5.1 数据资源类型

| 资源类型 | 类名 | 文件扩展 | 用途 |
|:---|:---|:---|:---|
| 卡牌数据 | CardResource | .tres | 定义卡牌属性、效果 |
| 环境数据 | EnvironmentResource | .tres | 定义环境效果、视觉 |
| 敌人数据 | EnemyResource | .tres | 定义敌人属性、AI |
| BOSS 数据 | BossResource | .tres | 定义 BOSS 属性、技能 |
| 状态数据 | StatusResource | .tres | 定义状态效果 |
| 建筑数据 | BuildingResource | .tres | 定义建筑功能 |

### 5.2 CardResource 详细设计

**基础信息**：
- card_id（唯一标识）
- card_name（显示名称）
- card_description（描述）
- card_icon（图标）
- card_art（卡图）

**卡牌属性**：
- energy_cost（能量消耗）
- card_type（类型：ATTACK/SKILL/POWER/CONSUMABLE）
- element_type（元素：FIRE/WATER/THUNDER/ICE/NORMAL）
- rarity（稀有度：COMMON/UNCOMMON/RARE/LEGENDARY）

**卡牌效果**：
- effects（效果列表，CardEffect 数组）
- target_type（目标类型：SELF/ENEMY/ALL_ENEMIES/ALLY）

**流派卡特性**：
- is_flow_card（是否为流派卡）
- flow_passive（被动效果）
- flow_trigger_condition（触发条件）

## 六、组件系统设计

### 6.1 组件模式说明

组件是可复用的功能模块，可附加到任何实体上：

```
Entity (Node2D)
├── HealthComponent        # 生命值
├── StatusComponent        # 状态效果
├── DamageComponent        # 伤害计算
├── AnimationComponent     # 动画控制
└── AIComponent (敌人专用) # AI 行为
```

### 6.2 HealthComponent 设计

**属性**：
- max_hp（最大生命值）
- current_hp（当前生命值）
- defense（防御力）

**方法**：
- take_damage(amount) → 实际伤害
- heal(amount) → 实际治疗
- die() → 死亡处理

**信号**：
- health_changed(current, max)
- died()

### 6.3 StatusComponent 设计

**属性**：
- active_statuses（当前状态字典）

**方法**：
- add_status(status_id, stacks, duration)
- remove_status(status_id)
- get_status_stacks(status_id)
- tick_statuses()

**信号**：
- status_added(status_id, stacks)
- status_removed(status_id)
- status_updated(status_id, stacks, duration)

## 七、系统模块设计

### 7.1 BattleSystem 战斗系统

**职责**：管理战斗全流程

**状态机**：
```
IDLE → PLAYER_TURN → ENEMY_TURN → RESOLUTION → (循环)
   ↓
  END (胜利/失败)
```

**核心方法**：
- start_battle(enemy_data)
- player_turn_start()
- enemy_turn_start()
- play_card(card, target)
- end_turn()
- check_battle_end()

### 7.2 CardSystem 卡牌系统

**职责**：管理卡牌逻辑

**核心功能**：
- 牌组管理（抽牌堆、手牌、弃牌堆、消耗堆）
- 抽牌逻辑
- 打牌逻辑
- 卡牌效果执行
- 流派卡被动管理

### 7.3 EnvironmentSystem 环境系统

**职责**：管理环境效果

**核心功能**：
- 环境切换
- 环境效果应用
- Shader 参数更新
- 全局 Modifier 计算

### 7.4 DamageSystem 伤害系统

**职责**：统一伤害计算

**计算流程**：
```
基础伤害
  ↓
+ 状态加成
  ↓
× 环境倍率
  ↓
- 防御减免
  ↓
× 暴击倍率
  ↓
最终伤害
```

### 7.5 ProgressionSystem 成长系统

**职责**：管理局外成长

**核心功能**：
- 基地建筑升级
- 卡牌仓库管理
- 解锁内容管理
- 成就系统

### 10.3 代码组织规范

```gdscript
# 1. 类继承
class_name MyClass extends Node

# 2. 信号定义
signal my_signal(arg1: int)

# 3. 常量定义
const MAX_VALUE = 100

# 4. Export 变量
@export var public_var: int = 0

var _private_var: int = 0

# 6. @onready 变量
@onready var sprite: Sprite2D = $Sprite2D

# 7. 生命周期函数
func _ready() -> void:
    pass

func _process(delta: float) -> void:
    pass

# 8. 公共方法
func public_method() -> void:
    pass

# 9. 私有方法
func _private_method() -> void:
    pass
```
