## 一、UI 设计风格规范

### 1. 设计原则

**核心理念**：简约 · 功能导向 · 沉浸式

- **简约**：去除多余装饰，信息层级清晰
- **功能导向**：每个 UI 元素都有明确用途
- **沉浸式**：UI 融入世界观，不破坏代入感

### 2. 视觉风格定义

**风格名称**：中世纪工业/科幻控制台

| 要素 | 规范 |
|:---|:---|
| **背景色** | 深色半透明 (#1A1A2EAA) |
| **主色调** | 琥珀色 (#FFB800) / 淡蓝色 (#00D4FF) |
| **文字色** | 白色 (#FFFFFF) / 灰色 (#AAAAAA) |
| **边框** | 2px 实线，颜色随功能变化 |
| **圆角** | 4px (小按钮) / 8px (大面板) |
| **阴影** | 轻微外阴影，增强层次感 |

### 3. 字体规范

| 用途 | 字体 | 大小 | 字重 |
|:---|:---|:---|:---|
| 标题 | 思源黑体 CN Bold | 24-32px | Bold |
| 正文 | 思源黑体 CN Regular | 14-16px | Regular |
| 数值 | JetBrains Mono | 16-20px | Medium |
| 按钮 | 思源黑体 CN Medium | 16px | Medium |

### 4. 图标规范

- **尺寸**：16x16 / 24x24 / 32x32 / 48x48 / 64x64
- **风格**：线性图标，2px 描边
- **颜色**：单色，通过颜色传达状态

### 2. 战斗 UI 组件详情

#### 2.1 环境信息区

| 元素 | 说明 | 尺寸 |
|:---|:---|:---|
| 环境图标 | 动态图标，显示当前环境 | 48x48 |
| 环境名称 | 文字显示 | - |
| 环境效果 | 简要文字说明当前环境效果 | - |

**Godot 实现**：
- 使用 `HBoxContainer` 水平排列
- 环境图标使用 `TextureRect`
- 背景使用半透明 `Panel`

#### 2.2 玩家区域

| 元素 | 说明 | 尺寸 |
|:---|:---|:---|
| 玩家头像/立绘 | 2D 角色展示 | 128x128 |
| 生命值条 | 绿色渐变，显示当前/最大 HP | 200x20 |
| 状态图标区 | 水平排列的状态图标 | 动态 |

**状态图标规范**：
- 尺寸：24x24
- 边框颜色：负面状态红色，正面状态蓝色
- 层数显示：右下角数字标签

#### 2.3 敌人区域

| 元素 | 说明 | 尺寸 |
|:---|:---|:---|
| 敌人立绘 | 2D 敌人展示 | 128x128 |
| 意图图标 | 显示下回合行动 | 48x48 |
| 意图数值 | 具体伤害/格挡值 | - |
| 生命值条 | 红色渐变 | 200x20 |
| 状态图标区 | 同玩家区域 | 动态 |

**意图图标类型**：
- ⚔️ 攻击：红色边框
- 🛡️ 防御：蓝色边框
- ⭐ 特殊：黄色边框
- ➕ 增益：绿色边框

#### 2.4 能量条区

**设计**：
- 电池造型，分段显示
- 已用能量：暗色
- 可用能量：亮色 (琥珀色)
- 尺寸：300x30

**Godot 实现**：
```gdscript
# EnergyBar.gd
@onready var segments: HBoxContainer = $Segments
@export var max_energy: int = 5
@export var current_energy: int = 3

func update_energy(current: int, max: int):
    for i in range(segments.get_child_count()):
        var segment = segments.get_child(i)
        if i < current:
            segment.modulate = Color(1, 0.72, 0)  # 琥珀色
        else:
            segment.modulate = Color(0.2, 0.2, 0.2)  # 暗色
```

#### 2.5 手牌区

**设计**：
- 扇形排列 (使用 `Tween` 动画)
- 卡牌尺寸：100x140
- 悬停放大：1.2 倍
- 选中上移：20px

**卡牌视觉规范**：
| 元素 | 说明 |
|:---|:---|
| 边框颜色 | 按稀有度：白/绿/蓝/紫/橙/红 |
| 消耗显示 | 左上角水晶图标 + 数字 |
| 卡牌图片 | 70x70 居中 |
| 卡牌名称 | 14px 居中 |
| 卡牌描述 | 10px 底部 |

#### 2.6 功能按钮区

| 按钮 | 尺寸 | 说明 |
|:---|:---|:---|
| 结束回合 | 160x50 | 右侧大按钮，绿色 |
| 技能按钮 | 120x50 | 显示冷却，灰色不可用时 |

## 六、动画与反馈

### 1. 交互动画

| 交互 | 动画 | 时长 |
|:---|:---|:---|
| 按钮悬停 | 亮度 +20% | 0.1s |
| 按钮按下 | 缩放 0.95 | 0.05s |
| 窗口打开 | 缩放 + 淡入 | 0.2s |
| 窗口关闭 | 缩放 + 淡出 | 0.15s |
| 卡牌抽牌 | 平移 + 扇形展开 | 0.3s |
| 卡牌打出 | 飞向目标 + 淡出 | 0.4s |

### 2. 反馈效果

| 事件 | 反馈 |
|:---|:---|
| 伤害 | 数字飘字 + 屏幕震动 |
| 暴击 | 大号金色数字 + 闪光 |
| 格挡 | 蓝色数字 + 盾牌图标 |
| 治疗 | 绿色数字 + 心形粒子 |
| 机制杀 | 全屏慢动作 + 特殊动画 |

### 3. Godot 实现示例

```gdscript
# 数字飘字
func show_damage_popup(target: Node2D, damage: int, is_crit: bool = false):
    var popup = damage_popup_scene.instantiate()
    popup.setup(damage, is_crit)
    get_tree().current_scene.add_child(popup)
    popup.global_position = target.global_position + Vector2(0, -50)
    
# 屏幕震动
func shake_camera(intensity: float, duration: float):
    var tween = create_tween()
    tween.tween_property(camera, "offset", Vector2(intensity, intensity), 0.05)
    tween.tween_property(camera, "offset", Vector2(-intensity, -intensity), 0.05)
    # ... 重复直到 duration 结束
```
