## 一、本地化概述

### 1. 设计目标

支持多语言，让游戏能够面向全球玩家，同时保持文化适配和翻译质量。

**支持语言**：
| 语言 | 代码 | 优先级 |
|:---|:---|:---:|
| 简体中文 | zh_CN | P0 |
| 繁体中文 | zh_TW | P0 |
| 英语 | en | P0 |
| 日语 | ja | P1 |
| 韩语 | ko | P1 |
| 德语 | de | P2 |
| 法语 | fr | P2 |
| 西班牙语 | es | P2 |

### 2. 本地化范围

| 内容类型 | 是否本地化 | 说明 |
|:---|:---:|:---|
| UI 文本 | ✅ | 所有界面文字 |
| 卡牌描述 | ✅ | 卡牌名称、效果 |
| 剧情文本 | ✅ | 对话、旁白 |
| 成就描述 | ✅ | 成就名称、说明 |
| 教程文本 | ✅ | 引导提示 |
| 音频 | ❌ | 首版本无配音 |
| 美术文字 | ⚠️ | 尽量使用可替换贴图 |

## 四、Godot 实现方案

### 1. 翻译管理器

```gdscript
# LocalizationManager.gd - 单例
class_name LocalizationManager extends Node

signal language_changed(locale: String)

var supported_locales: Array[String] = ["zh_CN", "zh_TW", "en", "ja", "ko"]
var current_locale: String = "zh_CN"

func _ready():
    # 自动检测系统语言
    var system_locale = get_system_locale()
    if system_locale in supported_locales:
        set_locale(system_locale)
    else:
        set_locale("zh_CN")  # 默认中文

func set_locale(locale: String):
    if locale not in supported_locales:
        push_warning("Locale not supported: ", locale)
        locale = "zh_CN"
    
    current_locale = locale
    TranslationServer.set_locale(locale)
    language_changed.emit(locale)
    
    # 保存设置
    save_language_preference()

func get_locale() -> String:
    return current_locale

func tr(text_key: String) -> String:
    return TranslationServer.translate(text_key)

func get_system_locale() -> String:
    var locale = OS.get_locale_language()
    # 映射系统语言到支持的语言
    var locale_map = {
        "zh": "zh_CN",
        "en": "en",
        "ja": "ja",
        "ko": "ko",
        "de": "de",
        "fr": "fr",
        "es": "es"
    }
    return locale_map.get(locale, "zh_CN")
```

### 2. UI 文本绑定

```gdscript
# LocalizedLabel.gd
class_name LocalizedLabel extends Label

@export var text_key: String

func _ready():
    LocalizationManager.language_changed.connect(_on_language_changed)
    update_text()

func _on_language_changed(_locale: String):
    update_text()

func update_text():
    if text_key:
        text = LocalizationManager.tr(text_key)
```

### 3. 动态文本

```gdscript
# 带参数的翻译
func tr_with_params(text_key: String, params: Dictionary) -> String:
    var template = TranslationServer.translate(text_key)
    for key in params:
        template = template.replace("{" + key + "}", str(params[key]))
    return template

# 使用示例
# 翻译模板："造成 {damage} 点伤害"
tr_with_params("card_effect_damage", {"damage": 10})
# 结果："造成 10 点伤害"
```

## 五、字体回退方案

### 1. 字体配置

```gdscript
# FontManager.gd
class_name FontManager extends Node

var font_mapping: Dictionary = {
    "zh_CN": ["res://assets/fonts/NotoSansSC-Regular.ttf", "res://assets/fonts/NotoSansSC-Bold.ttf"],
    "zh_TW": ["res://assets/fonts/NotoSansTC-Regular.ttf", "res://assets/fonts/NotoSansTC-Bold.ttf"],
    "en": ["res://assets/fonts/NotoSans-Regular.ttf", "res://assets/fonts/NotoSans-Bold.ttf"],
    "ja": ["res://assets/fonts/NotoSansJP-Regular.ttf", "res://assets/fonts/NotoSansJP-Bold.ttf"],
    "ko": ["res://assets/fonts/NotoSansKR-Regular.ttf", "res://assets/fonts/NotoSansKR-Bold.ttf"]
}

func get_font_for_locale(locale: String) -> FontFile:
    var fonts = font_mapping.get(locale, font_mapping["zh_CN"])
    var font = FontFile.new()
    font.font_data = load(fonts[0]).font_data
    return font
```

### 2. 字体回退链

```
主字体 → 中文支持 → 日文支持 → 韩文支持 → 系统字体

Godot 4.x 支持字体回退：
- 主字体：Noto Sans（西文）
- 回退 1: Noto Sans SC（简体中文）
- 回退 2: Noto Sans JP（日文）
- 回退 3: Noto Sans KR（韩文）
```

### 3. Theme 配置

```gdscript
# 为不同语言设置不同字体
func setup_language_theme(locale: String):
    var theme = Theme.new()
    var font = FontManager.get_font_for_locale(locale)
    
    # 设置默认字体
    theme.default_font = font
    
    # 设置不同大小的字体
    theme.set_font("Title", "Label", FontManager.get_bold_font(locale))
    theme.set_font("Body", "Label", font)
    
    return theme
```

## 六、文化适配注意事项

### 1. 文本长度

| 语言 | 相对中文长度 | 注意事项 |
|:---|:---:|:---|
| 中文 | 1.0x | 基准 |
| 英语 | 1.5-2.0x | 需要更多空间 |
| 德语 | 2.0-2.5x | 单词很长 |
| 日语 | 1.0-1.2x | 假名 + 汉字 |
| 韩语 | 1.2-1.5x | 音节块 |

**UI 设计建议**：
- 按钮宽度预留 2 倍空间
- 使用自动换行
- 避免固定宽度容器

### 2. 日期格式

```gdscript
# 使用 Godot 的本地化日期
func format_date_localized(date: Dictionary) -> String:
    # Godot 4.x
    return Time.get_date_string_from_unix_time(Time.get_unix_time_from_datetime_dict(date))
```

| 地区 | 日期格式 | 示例 |
|:---|:---|:---|
| 中国 | YYYY-MM-DD | 2026-03-10 |
| 美国 | MM/DD/YYYY | 03/10/2026 |
| 欧洲 | DD.MM.YYYY | 10.03.2026 |
| 日本 | YYYY 年 MM 月 DD 日 | 2026 年 03 月 10 日 |

### 3. 数字格式

## 七、翻译工作流程

### 1. 文本提取


```
└─────────────────────────────────────────────────────────────┘
```

### 2. Godot 实现

```gdscript
# LanguageSettings.gd
class_name LanguageSettings extends PanelContainer

@onready var language_list: VBoxContainer = $VBoxContainer/LanguageList
@onready var confirm_button: Button = $VBoxContainer/ConfirmButton

var selected_locale: String = ""

func _ready():
    populate_languages()
    selected_locale = LocalizationManager.get_locale()
    update_selection()

func populate_languages():
    var languages = {
        "zh_CN": "简体中文",
        "zh_TW": "繁體中文",
        "en": "English",
        "ja": "日本語",
        "ko": "한국어",
        "de": "Deutsch",
        "fr": "Français",
        "es": "Español"
    }
    
    for locale in languages:
        var button = RadioButton.new()
        button.text = languages[locale]
        button.meta = locale
        button.toggled.connect(_on_language_toggled.bind(locale))
        language_list.add_child(button)

func _on_language_toggled(toggled: bool, locale: String):
    if toggled:
        selected_locale = locale

func on_confirm():
    LocalizationManager.set_locale(selected_locale)
    hide()
```
