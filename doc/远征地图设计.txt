## 一、远征系统概述

**核心设计原则**：
- **固定地图布局**：节点位置固定，方便美术制作
- **随机地图选取**：每局从地图池中随机选择一张地图
- **节点环境固定**：每个节点绑定固定环境类型
- **节点事件随机**：战斗敌人、事件内容随机

**远征流程**：
```
基地准备 → 选择难度 → 随机地图 → 节点探索 → BOSS 战 → 撤离
```

**远征时长**：
- 战斗场次：10-15 场
- 预计耗时：1.5-2.5 小时
- 单场战斗：2-7 分钟

## 二、地图池设计

### 1. 固定地图列表

预设 **5 张固定地图**，每局随机选择 1 张：

| 地图 ID | 名称 | 主题 | 主要环境 | 难度 | 区域 |
|:---|:---|:---|:---|:---|:---|
| map_a | 边境荒野 | 新手教学 | 晴朗/雨天 | 简单 | 区域 1 |
| map_b | 污染沼泽 | 毒素环境 | 毒雾/晴朗 | 中等 | 区域 2 |
| map_c | 火山地带 | 高温环境 | 高温/晴朗 | 中等 | 区域 2 |
| map_d | 冰川裂隙 | 寒冷环境 | 寒冷/晴朗 | 困难 | 区域 3 |
| map_e | 深渊遗迹 | 异常环境 | 高重力/时空紊乱 | 极难 | 区域 4 |

### 2. 地图选取规则

**普通难度**：
- 可选地图：map_a, map_b, map_c
- 随机权重：map_a 50%, map_b 25%, map_c 25%

**困难难度**：
- 可选地图：map_b, map_c, map_d
- 随机权重：各 33%

**极难 + 难度**：
- 可选地图：map_c, map_d, map_e
- 随机权重：map_e 50%, 其他各 25%

## 四、节点系统设计

### 1. 节点类型

| 类型 | 图标 | 说明 | 环境绑定 |
|:---|:---|:---|:---|
| 起点 | 🟢 | 远征起始点，安全 | 晴朗 |
| 战斗 | ⚔️ | 触发战斗 | 固定 |
| 精英 | ⚔️🔴 | 强化战斗 | 固定 |
| 事件 | ❓ | 随机事件 | 固定 |
| 安全屋 | 🏠 | 休息整备 | 晴朗 |
| BOSS | 👑 | 区域首领 | 固定 |

### 2. 战斗节点随机规则

**敌人组合随机**：
- 从节点敌人池中随机选择 1-3 个敌人
- 至少 1 个普通敌人
- 难度越高，敌人数量越多

**示例（节点 A1）**：
```
敌人池：[流寇，野猪，哥布林]

可能组合：
- 流寇 ×1
- 流寇 ×2
- 野猪 ×2
- 哥布林 ×3
- 流寇 ×1 + 哥布林 ×2
```

### 3. 事件节点随机规则

**事件池分类**：

**奖励事件（40%）**：
| 事件 | 效果 |
|:---|:---|
| 补给空投 | 获得 2-3 个消耗品 |
| 废弃营地 | 获得金币 30-50 |
| 神秘商人 | 可购买稀有物品 |
| 卡牌研究者 | 升级一张卡牌 |

**中性事件（30%）**：
| 事件 | 效果 |
|:---|:---|
| 迷路 | 选择一条路径前进 |
| 时间异常 | 临时效果 |
| 神秘祭坛 | 用生命换取奖励 |

**负面事件（30%）**：
| 事件 | 效果 |
|:---|:---|
| 伏击 | 强制战斗（削弱状态） |
| 环境灾害 | 失去 10-20 生命 |
| 诅咒 | 获得一张诅咒卡 |

## 五、环境绑定规则

### 1. 环境 - 节点绑定

每个节点在地图设计时即绑定固定环境：

```json
{
  "node_id": "A1",
  "type": "battle",
  "environment": "sunny",
  "position": {"x": 100, "y": 200}
}
```

### 2. 战斗环境应用

进入战斗时，自动应用节点绑定的环境：

```gdscript
func start_battle(node_data):
    var env_type = node_data.environment
    EnvironmentManager.set_environment(env_type)
```

### 3. 环境效果

环境效果参考 `环境系统设计.txt`：

## 七、路径与连接规则

### 1. 连接规则

- 每个节点有 1-3 个连接
- 路径不交叉（类似杀戮尖塔）
- BOSS 节点是所有路径的汇合点

### 2. 路径选择

玩家在每个节点可以选择 1 个相邻节点前进：

```
当前节点 → 选择相邻节点 → 移动 → 触发节点事件
```

### 3. 回溯规则

- 不允许回溯到已访问节点
- 只能向前进方向移动
- BOSS 战后远征结束（撤离或继续下一区域）

## 九、Godot 技术实现

### 1. 场景树结构

```
MapScene (Node2D)
├── MapBackground (Sprite2D)        # 地图背景
├── NodeManager (Node)
│   ├── NodeContainer (Node2D)      # 节点容器
│   │   ├── MapNode (Node2D)        # 节点实例（多个）
│   │   └── ConnectionLine (Line2D) # 连接线
│   └── PathContainer (Node2D)      # 路径容器
├── UI_Layer (CanvasLayer)
│   ├── NodeInfoPanel (Panel)       # 节点信息
│   └── ConfirmationDialog (Window) # 确认对话框
└── MapManager (Node)               # 地图逻辑
```

### 2. 地图管理器脚本

```gdscript
class_name MapManager extends Node

@export var map_configs: Array[Resource]  # 地图配置资源
var current_map: Dictionary
var current_node: String
var visited_nodes: Array[String]

func start_expedition(difficulty: String):
    # 根据难度选择地图
    var available_maps = get_available_maps(difficulty)
    current_map = select_random_map(available_maps)
    load_map(current_map)

func select_node(node_id: String):
    # 移动到指定节点
    current_node = node_id
    visited_nodes.append(node_id)
    trigger_node_event(current_map.nodes[node_id])

func trigger_node_event(node_data: Dictionary):
    # 触发节点事件
    match node_data.type:
        "battle":
            start_battle(node_data)
        "event":
            start_event(node_data)
        "safehouse":
            open_safehouse(node_data)
        "boss":
            start_boss_battle(node_data)
```

### 3. 节点实例脚本

```gdscript
class_name MapNode extends Node2D

@export var node_data: Dictionary
@onready var sprite: Sprite2D = $Sprite2D
@onready var icon: TextureRect = $Icon

func setup(data: Dictionary):
    node_data = data
    update_visual_state()

func update_visual_state():
    # 根据节点状态更新视觉
    if node_data.id in MapManager.visited_nodes:
        set_state("visited")
    elif is_reachable():
        set_state("reachable")
    else:
        set_state("locked")

func is_reachable() -> bool:
    # 检查是否可达
    for conn in node_data.connections:
        if conn == MapManager.current_node:
            return true
    return false
```

## 十、随机性与重复可玩性

### 1. 随机性来源

| 来源 | 说明 | 每局变化 |
|:---|:---|:---|
| 地图选择 | 从地图池随机 | ✅ |
| 敌人组合 | 从敌人池随机 | ✅ |
| 事件内容 | 从事件池随机 | ✅ |
| 掉落奖励 | 概率随机 | ✅ |
| 商店商品 | 随机刷新 | ✅ |

### 2. 固定性保证

| 内容 | 说明 | 每局变化 |
|:---|:---|:---|
| 节点位置 | 地图布局固定 | ❌ |
