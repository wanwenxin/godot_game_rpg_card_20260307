## 一、远征系统概述

远征是游戏的核心玩法循环，玩家从基地出发，穿越多个区域，最终击败最终 BOSS 并撤离。

### 1. 远征流程
```
基地准备 → 选择路线 → 战斗节点 → 事件节点 → BOSS 战 → 撤离/继续
```

### 2. 远征时长设计
- **战斗场次**：10-15 场（不含重复战斗）
- **预计耗时**：1.5-2.5 小时（含卡组构建时间）
- **单场战斗**：2-7 分钟

### 3. 远征目标
- **主要目标**：击败最终 BOSS
- **次要目标**：收集稀有素材、完成机制杀
- **隐藏目标**：解锁隐藏结局

## 二、地图结构设计

### 1. 整体架构

远征地图采用**分区域爬塔式**结构：

```
基地
  │
  ▼
区域 1（3-4 节点）
  │
  ▼
区域 2（3-4 节点）
  │
  ▼
区域 3（3-4 节点）
  │
  ▼
区域 4（最终区域，2-3 节点）
  │
  ▼
撤离点
```

### 2. 节点类型

| 节点类型 | 图标 | 数量占比 | 说明 |
|:---|:---:|:---:|:---|
| 普通战斗 | ⚔️ | 50% | 基础战斗，掉落基础素材 |
| 精英战斗 | ⚔️🔴 | 20% | 强力敌人，掉落稀有素材 |
| BOSS 战 | 👑 | 4 场固定 | 区域最终首领 |
| 事件节点 | ❓ | 15% | 随机事件，可能获得奖励或负面效果 |
| 安全屋 | 🏠 | 10% | 回复、整备、商店 |
| 极端环境 | ⚠️ | 5% | 高风险高回报区域 |

### 3. 节点连接规则

- 每个节点有 2-3 个前进选择
- 节点间路径不交叉（类似杀戮尖塔）
- BOSS 节点前有固定精英节点
- 安全屋不会连续出现

## 四、节点详细设计

### 1. 普通战斗节点

**触发条件**：进入节点自动触发

**敌人配置**：
- 区域 1:1-2 个普通敌人
- 区域 2:2-3 个普通敌人或 1 精英
- 区域 3:2-3 个普通敌人
- 区域 4:3-4 个普通敌人或 2 精英

**胜利奖励**：
```
基础奖励：
  - 货币：10-20
  - 基础素材：1-3
  
概率奖励：
  - 卡牌：10%
  - 消耗品：20%
  - 额外货币：30%
```

---

### 2. 精英战斗节点

**触发条件**：进入节点自动触发

**敌人配置**：
- 1 个精英敌人
- 或 2 个强化普通敌人

**胜利奖励**：
```
基础奖励：
  - 货币：30-50
  - 稀有素材：1-2
  
概率奖励：
  - 核心卡牌：30%
  - 高级消耗品：20%
  - 天赋选择：50%
```

---

### 3. BOSS 节点

**触发条件**：前置节点全部完成后解锁

**战斗规则**：
- 多阶段战斗
- 专属环境效果
- 机制杀可选

**胜利奖励**：
```
固定奖励：
  - BOSS 核心：1
  - 稀有货币：5-10
  - 核心卡牌：1
  
概率奖励：
  - 蓝图碎片：50%
  - 机制杀材料：机制杀触发
```

---

### 4. 事件节点

**触发条件**：进入节点随机触发事件

**事件类型**：

**奖励事件**（40%）：
| 事件 | 效果 |
|:---|:---|
| 补给空投 | 获得 2-3 个消耗品 |
| 废弃营地 | 获得货币 30-50 |
| 神秘商人 | 可购买稀有物品 |
| 卡牌研究者 | 升级一张卡牌 |

**中性事件**（30%）：
| 事件 | 效果 |
|:---|:---|
| 迷路 | 选择一条路径前进 |
| 时间异常 | 失去 1 回合或获得 1 能量上限（临时） |
| 神秘祭坛 | 用生命换取奖励 |

**负面事件**（30%）：
| 事件 | 效果 |
|:---|:---|
| 伏击 | 强制战斗（ weakened 状态） |
| 环境灾害 | 失去 10-20 生命 |
| 诅咒 | 获得一张诅咒卡 |

---

### 5. 安全屋节点

**触发条件**：进入节点自动触发

**功能**：
- **休息**：回复 30% 生命值
- **整备**：调整卡组（添加/移除卡牌）
- **制造**：使用素材制造消耗品
- **商店**：购买卡牌、消耗品、素材

**商店商品**：
| 商品类型 | 数量 | 价格范围 |
|:---|:---|:---|
| 基础卡牌 | 3 | 20-40 货币 |
| 稀有卡牌 | 1 | 80-120 货币 |
| 消耗品 | 3 | 10-50 货币 |
| 素材 | 2 | 30-60 货币 |
| 神秘商品 | 1 | 100+ 货币 |

---

### 6. 极端环境节点

**触发条件**：进入节点自动触发

**环境类型**：
- 雷暴区域
- 毒雾深处
- 高重力点
- 时空裂缝

**特殊规则**：
- 敌人获得环境增益
- 玩家获得环境减益
- 胜利后额外奖励

**奖励**：
```
固定奖励：
  - 环境核心：1
  - 货币：50-80
  
概率奖励：
  - 流派核心卡：30%
  - 天赋选择：50%
```

## 五、路径选择系统

### 1. 路径规则

- 每次远征有 3-4 条主要路径
- 路径间可通过特殊节点切换
- BOSS 节点所有路径汇合

### 2. 路径难度

| 路径类型 | 难度 | 奖励系数 | 推荐 |
|:---|:---:|:---:|:---|
| 安全路径 | 低 | 1.0x | 新手 |
| 普通路径 | 中 | 1.2x | 一般 |
| 危险路径 | 高 | 1.5x | 进阶 |
| 隐藏路径 | 极高 | 2.0x | 挑战 |

### 3. 隐藏路径解锁

**解锁条件**：
- 完成特定机制杀
- 收集全部 BOSS 核心
- 携带特定卡牌组合

**入口位置**：
- 区域 2 后随机出现
- 需要特殊道具开启

---

## 六、撤离系统

### 1. 撤离点位置

- 最终 BOSS 战后固定出现
- 部分安全屋可能提供提前撤离选项

### 2. 撤离奖励计算

```
基础奖励 = 战斗胜利货币总和 × 0.5
物资奖励 = 携带素材 × 1.0
额外奖励 = 机制杀次数 × 50 + BOSS 核心数 × 100

总奖励 = 基础奖励 + 物资奖励 + 额外奖励
```

### 3. 提前撤离

**规则**：
- 可在安全屋选择提前撤离
- 获得已收集资源的 50%
- 远征进度重置

**策略意义**：
- 资源不足时及时止损
- 测试新流派后快速返回

---

## 七、负重系统

### 1. 负重规则

- 背包有容量上限
- 不同素材占用不同空间
- 超重影响撤离奖励

**背包容量**：
```
基础容量：20 格
基地升级：+5 格/级（最大 50 格）
天赋加成：+5 格
```

### 2. 物品占用

| 物品类型 | 占用格数 |
|:---|:---:|
| 基础素材 | 1 |
| 稀有素材 | 2 |
| BOSS 核心 | 3 |
| 消耗品 | 1 |
| 蓝图碎片 | 2 |

### 3. 负重惩罚

```
负重 ≤ 50%: 无惩罚
负重 50%-80%: 无影响
负重 80%-100%: 商店价格 +10%
负重 > 100%: 无法拾取新物品，撤离奖励 -20%
```

## 九、远征进度保存

### 1. 保存时机

- 每场战斗结束后自动保存
- 节点选择后自动保存
- 手动保存选项

### 2. 保存内容

```json
{
  "expedition_id": "unique_id",
  "current_zone": 2,
  "current_node": "elite_3",
  "player_state": {
    "hp": 150,
    "deck": [...],
    "inventory": [...]
  },
  "completed_nodes": ["node_1", "node_2"],
  "statistics": {
    "battles": 5,
    "mechanic_kills": 2
  }
}
```

### 3. 中断恢复

- 意外退出后可恢复远征
- 保存有效期：7 天
- 恢复时显示上次进度

## 十、每日远征

### 1. 每日挑战

- 每日刷新特殊远征路线
- 固定种子保证公平
- 全球玩家相同挑战

### 2. 每日奖励

| 完成度 | 奖励 |
|:---|:---|
| 到达区域 2 | 50 货币 |
| 到达区域 3 | 100 货币 |
| 击败最终 BOSS | 200 货币 + 稀有卡牌 |

### 3. 每日词缀

每日远征有随机词缀：
- 火焰日：火系卡牌 +20% 伤害
- 重力日：所有单位获得重力
- 经济日：货币获取 +50%
