## 一、远征系统概述

**核心设计原则**：
- **横向卷轴布局**：地图从左往右延伸，视觉化进度更清晰
- **固定地图布局**：节点位置固定，方便美术制作
- **随机地图选取**：每局从地图池中随机选择一张地图
- **节点环境固定**：每个节点绑定固定环境类型
- **节点事件随机（有规则）**：战斗敌人、事件内容随机，但遵循分布规则
- **难度资源递增**：越往后的节点获取的资源越多，难度越高

**远征流程**：
```
基地准备 → 选择难度 → 随机地图 → 节点探索（从左往右） → BOSS 战 → 撤离
```

**远征时长**：
- 战斗场次：10-12 场
- 预计耗时：2.5-3 小时
- 单场战斗：2-7 分钟

**地图结构**：
- 节点总数：15-18 个
- 列数：6-7 列（从左往右推进）
- 每列节点数：2-3 个（多路径选择）

## 二、地图池设计

### 1. 固定地图列表

预设 **5 张固定地图**，每局随机选择 1 张：

| 地图 ID | 名称 | 主题 | 主要环境 | 难度 | 区域 | 节点数 |
|:---|:---|:---|:---|:---|:---|:---:|
| map_a | 边境荒野 | 新手教学 | 晴朗/雨天 | 简单 | 区域 1 | 15 |
| map_b | 污染沼泽 | 毒素环境 | 毒雾/晴朗 | 中等 | 区域 2 | 16 |
| map_c | 火山地带 | 高温环境 | 高温/晴朗 | 中等 | 区域 2 | 17 |
| map_d | 冰川裂隙 | 寒冷环境 | 寒冷/晴朗 | 困难 | 区域 3 | 18 |
| map_e | 深渊遗迹 | 异常环境 | 高重力/时空紊乱/虚空 | 极难 | 区域 4 | 18 |

### 2. 地图选取规则

**普通难度**：
- 可选地图：map_a, map_b, map_c
- 随机权重：map_a 50%, map_b 25%, map_c 25%

**困难难度**：
- 可选地图：map_b, map_c, map_d
- 随机权重：各 33%

**极难 + 难度**：
- 可选地图：map_c, map_d, map_e
- 随机权重：map_e 50%, 其他各 25%

### 3. 资源倍率系统

| 进度 | 列数 | 资源倍率 | 金币倍率 | 稀有掉落率 | 敌人强度系数 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 前期 | 第 1-2 列 | 1.0x | 1.0x | 5% | 1.0 |
| 前期 | 第 3 列 | 1.2x | 1.2x | 10% | 1.3 |
| 中期 | 第 4 列 | 1.5x | 1.5x | 15% | 1.6 |
| 后期 | 第 5 列 | 2.0x | 1.8x | 20% | 2.0 |
| 后期 | 第 6 列 | 2.5x | 2.0x | 25% | 2.5 |
| BOSS | BOSS 节点 | 3.0x | 2.5x | 35% | 3.0+ |
| 隐藏 | 隐藏节点 | 3.0x-5.0x | 3.0x | 40% | 2.0-3.0 |

**敌人强度计算公式**：
```
敌人强度 = 基础强度 × (1 + 列数 × 0.15) × 难度系数
```

## 四、节点系统设计

### 0. 节点事件随机规则

**设计原则**：随机但有规则，避免极端情况，保证游戏体验

#### 类型分布规则

| 列数 | 战斗节点 | 事件节点 | 安全屋 | 说明 |
|:---:|:---:|:---:|:---:|:---|
| 第 1-2 列 | 100% | 0% | 0% | 前期以战斗教学为主 |
| 第 3-4 列 | 80% | 20% | 0% | 开始引入事件 |
| 第 5 列 | 60% | 20% | 20% | 安全屋出现 |
| 第 6 列 | 100% (BOSS) | 0% | 0% | 最终决战 |

#### 事件保底规则

| 规则 | 说明 |
|:---|:---|
| **奖励事件保底** | 每局至少触发 2 个奖励事件，若前 5 个节点未触发，第 6 个节点强制奖励事件 |
| **负面事件间隔** | 连续 2 个负面事件后，下个节点必为奖励/中性事件 |
| **安全屋间隔** | 安全屋之间至少间隔 2 列，防止过于频繁的补给 |
| **事件权重调整** | 若已触发过同类事件，该事件权重降低 50% |

#### 敌人组合规则

| 规则 | 说明 |
|:---|:---|
| **最低数量** | 至少 1 个普通敌人 |
| **精英限制** | 精英敌人只在第 3 列后出现 |
| **难度关联** | 难度越高，敌人数量越多（1-3 个） |
| **威胁值影响** | 威胁值 61+ 时，20% 概率出现额外精英敌人 |

#### 环境波动规则

| 规则 | 说明 |
|:---|:---|
| **波动数量** | 每局 1-2 个节点发生环境变化 |
| **变化显示** | 变化节点在地图上显示"？"，到达后揭晓实际环境 |
| **变化范围** | 只能变为相邻环境类型（如晴朗→雨天，不能晴朗→虚空） |

### 1. 节点类型

| 类型 | 图标 | 说明 | 环境绑定 |
|:---|:---|:---|:---|
| 起点 | 🟢 | 远征起始点，安全 | 晴朗 |
| 战斗 | ⚔️ | 触发战斗 | 固定 |
| 精英 | ⚔️🔴 | 强化战斗（地图 E） | 固定 |
| 事件 | ❓ | 随机事件 | 固定 |
| 安全屋 | 🏠 | 休息整备，功能丰富 | 晴朗 |
| BOSS | 👑 | 区域首领 | 固定 |
| 隐藏 | ✨ | 隐藏节点，满足条件解锁 | 固定 |

### 2. 列式布局规则

**设计原则**：
- 每列 2-3 个节点，提供多路径选择
- 玩家只能从当前列前往下一列
- 不可回溯到已通过的列
- BOSS 节点位于最后一列

**路径连接规则**：
```
第 1 列节点 → 可前往第 2 列相邻节点
第 2 列节点 → 可前往第 3 列相邻节点
...
第 5 列节点 → 可前往第 6 列 BOSS 节点
```

### 3. 战斗节点随机规则

**敌人组合随机**：
- 从节点敌人池中随机选择 1-3 个敌人
- 至少 1 个普通敌人
- 难度越高，敌人数量越多
- 后期节点可能出现精英敌人

**示例（节点 A1）**：
```
敌人池：[流寇，野猪，哥布林]

可能组合：
- 流寇 ×1
- 流寇 ×2
- 野猪 ×2
- 哥布林 ×3
- 流寇 ×1 + 哥布林 ×2
```

### 4. 隐藏节点详解

#### 什么是隐藏节点？

**隐藏节点**是一种特殊类型的地图节点，具有以下特点：

1. **不直接显示在地图上**：初始状态下不可见，地图上可能显示为"？"或完全不显示
2. **需要满足条件解锁**：达成特定条件后才会出现/解锁
3. **高风险高回报**：敌人较强，但资源倍率极高（3.0x-5.0x）
4. **每局只能访问一次**：访问后节点消失

#### 隐藏节点作用

| 作用 | 说明 |
|:---|:---|
| **资源获取** | 高倍率资源掉落（3.0x-5.0x），是普通节点的 2-3 倍 |
| **稀有掉落** | 40% 稀有掉落率，可能获得限定卡牌/蓝图 |
| **成就解锁** | 访问所有隐藏节点可解锁成就 |
| **流派验证** | 检验玩家当前构筑是否足够强大 |
| **多周目动力** | 鼓励玩家尝试不同流派和策略 |

#### 隐藏节点访问流程

```
1. 到达隐藏节点所在列（通常是第 5 列）
2. 检查是否满足解锁条件
3. 若满足，弹出提示"发现隐藏路径！"
4. 玩家选择是否前往
5. 进入隐藏节点，触发特殊战斗
6. 胜利后获得高倍率资源和稀有掉落
7. 节点消失，继续前往 BOSS 节点
```

#### 各地图隐藏节点设计

| 地图 | 隐藏节点 ID | 解锁条件 | 敌人 | 资源倍率 | 特殊掉落 |
|:---|:---|:---|:---|:---:|:---|
| 地图 A | A14 | 无（固定存在） | 特殊敌人 | 3.0x | 基础蓝图 |
| 地图 B | B15 | 在 B13 安全屋完成支线任务 | 毒雾精英×2 | 3.5x | 毒素配方 |
| 地图 C | C14 | 携带火系核心卡≥3 张 | 火元素领主 | 4.0x | 火焰核心卡 |
| 地图 D | D16 | 生命值≥80% 到达第 5 列 | 冰霜精英×2 | 4.5x | 冰系天赋 |
| 地图 E | E14 | 无负面状态到达第 5 列 | 虚空领主 | 5.0x | 稀有蓝图/限定卡 |

## 五、安全屋系统优化

### 1. 安全屋功能列表

| 功能 | 描述 | 消耗 | 解锁条件 |
|:---|:---|:---|:---|
| **深度休息** | 恢复 100% 生命，移除所有负面状态 | 消耗 1 个食物 | 默认 |
| **卡牌调整** | 可替换/升级/移除任意卡牌 | 免费 | 默认 |
| **消耗品制造** | 使用携带的材料制造消耗品 | 材料×2-3 | 默认 |
| **情报分析** | 查看后续 3 个节点的类型和环境 | 金币×20 | 默认 |
| **装备维护** | 升级一张核心卡的等级（+1） | 材料×3 | 实验室 Lv.3 |
| **状态重置** | 重置威胁值 | 金币×50 | 指挥部 Lv.3 |
| **紧急补给** | 用金币兑换消耗品（1.5 倍价格） | 金币×30/个 | 默认 |
| **撤离准备** | 设置撤离点，可随时返回此安全屋 | 消耗"撤离装置"×1 | 制造厂 Lv.2 |

### 2. 安全屋事件链

**安全屋有概率触发特殊事件**：

| 事件名 | 触发概率 | 效果 |
|:---|:---:|:---|
| **神秘商人** | 20% | 稀有商品，价格 -30%，可购买核心卡 |
| **流浪工匠** | 15%（携带材料≥10） | 免费升级一张卡牌 |
| **受伤士兵** | 25%（第 3 列后） | 治疗后获得情报（BOSS 弱点信息） |
| **古代记录** | 10%（首次到达） | 解锁隐藏节点位置 |
| **时空祝福** | 5%（第 4 列后） | 获得一个临时 Buff（持续 3 场战斗：伤害 +10% 或 防御 +15%） |
| **流派导师** | 10%（携带某流派≥3 张） | 获得该流派专属强化 |

**注**：原"时间异常"事件已移除，替换为"时空祝福"，避免回溯机制破坏游戏节奏

## 六、撤离机制

### 1. 撤离类型

| 撤离类型 | 触发条件 | 收益 |
|:---|:---|:---|
| **紧急撤离** | 任意战斗节点后 | 带回 50% 资源 |
| **计划撤离** | 安全屋使用撤离装置 | 带回 80% 资源 |
| **胜利撤离** | 击败 BOSS 后 | 带回 100% 资源 + 额外奖励 |
| **完美撤离** | 完美胜利撤离 | 带回 120% 资源 + 稀有蓝图 |

### 2. 完美胜利条件

- 无角色死亡（HP 从未低于 1）
- 回合数≤目标回合数（BOSS 战 10 回合内）
- 触发机制杀（使用流派专属终结）

### 3. 撤离点设置

**地图 A-D**：
- 击败 BOSS 后自动撤离

**地图 E**：
- 击败 E17 后可选择：
  - 立即撤离（带回 100% 资源）
  - 继续挑战 E18 真 BOSS（高风险高回报）

### 2. 地图管理器脚本

```gdscript
class_name MapManager extends Node

signal column_changed(column: int)
signal node_entered(node_data: Dictionary)

@export var map_configs: Array[Resource]  # 地图配置资源
var current_map: Dictionary
var current_node: String
var current_column: int = 0
var visited_nodes: Array[String] = []
var threat_value: int = 0

# 事件保底追踪
var reward_events_triggered: int = 0
var consecutive_negative_events: int = 0

func start_expedition(difficulty: String):
    # 根据难度选择地图
    var available_maps = get_available_maps(difficulty)
    current_map = select_random_map(available_maps)
    load_map(current_map)
    current_column = 0
    reward_events_triggered = 0
    consecutive_negative_events = 0

func select_node(node_id: String):
    # 移动到指定节点
    var node_data = get_node_data(node_id)
    if node_data.column != current_column + 1:
        return  # 只能前往下一列
    
    current_node = node_id
    visited_nodes.append(node_id)
    
    # 检查列变化
    if node_data.column > current_column:
        current_column = node_data.column
        column_changed.emit(current_column)
    
    trigger_node_event(node_data)

func get_available_nodes() -> Array:
    # 获取当前可选择节点（下一列相邻节点）
    var available = []
    for node in current_map.nodes:
        if node.column == current_column + 1:
            if is_node_reachable(node):
                available.append(node)
    return available

func is_node_reachable(node_data: Dictionary) -> bool:
    # 检查是否可达（与当前节点有连接）
    for conn in node_data.connections:
        if conn == current_node:
            return true
    # 起点可前往第 1 列所有节点
    if current_node == "start" and node_data.column == 1:
        return true
    return false

func get_resource_multiplier(column: int) -> float:
    # 获取列资源倍率
    match column:
        1, 2: return 1.0
        3: return 1.2
        4: return 1.5
        5: return 2.0
        6: return 2.5
        _: return 1.0

func update_threat(action: String):
    # 更新威胁值
    match action:
        "quick_win": threat_value += 5
        "power_card": threat_value += 3
        "consecutive_win": threat_value += 2
        "rest": threat_value = max(0, threat_value - 10)
        "extract": threat_value = max(0, threat_value - 20)

func trigger_node_event(node_data: Dictionary):
    # 节点事件触发逻辑
    if node_data.type == "battle":
        trigger_battle(node_data)
    elif node_data.type == "event":
        trigger_random_event(node_data)
    elif node_data.type == "safehouse":
        trigger_safehouse(node_data)

func trigger_random_event(node_data: Dictionary):
    # 检查保底规则
    if reward_events_triggered < 2 and visited_nodes.size() >= 6:
        # 强制奖励事件
        force_reward_event()
        return
    
    if consecutive_negative_events >= 2:
        # 强制奖励/中性事件
        force_positive_or_neutral_event()
        return
    
    # 正常随机事件
    var event_pool = get_event_pool_for_column(node_data.column)
    var selected_event = select_event_with_weights(event_pool)
    execute_event(selected_event)

func record_event_result(event_type: String):
    # 记录事件结果用于保底规则
    if event_type == "reward":
        reward_events_triggered += 1
        consecutive_negative_events = 0
    elif event_type == "negative":
        consecutive_negative_events += 1
```

- 在地图上方显示当前列数（如"第 3 列/共 6 列"）
- 每列进度标记
- 资源倍率显示

## 十二、随机性与重复可玩性

### 1. 随机性来源

| 来源 | 说明 | 每局变化 |
|:---|:---|:---|
| 地图选择 | 从地图池随机 | ✅ |
| 敌人组合 | 从敌人池随机 | ✅ |
| 事件内容 | 从事件池随机（有保底规则） | ✅ |
| 安全屋事件 | 概率触发特殊事件 | ✅ |
| 环境波动 | 1-2 个节点环境变化 | ✅ |
| 掉落奖励 | 概率随机 | ✅ |
| 隐藏节点 | 条件满足时解锁 | ✅ |

### 2. 固定性保证

| 内容 | 说明 | 每局变化 |
|:---|:---|:---|
| 节点位置 | 地图布局固定 | ❌ |
| 节点类型 | 战斗/事件/安全屋固定 | ❌ |
| 节点环境 | 环境绑定固定（波动除外） | ❌ |
| 连接关系 | 路径连接固定 | ❌ |
| 资源倍率 | 按列固定 | ❌ |

### 3. 重复可玩性

- 5 张不同地图，每局体验不同
- 多路径选择，每局路线不同
- 隐藏节点探索（5 种不同条件）
- 安全屋事件随机（6 种事件）
- 威胁值系统增加变数
- 不同流派需要不同策略
- 收集要素鼓励多周目
